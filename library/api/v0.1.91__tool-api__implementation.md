## Minimum Viable Wiring (4 steps)

### 1. Import and construct

```js
import { SgToolApi } from '/core/sg-tool-api/v0/v0.1/v0.1.0/sg-tool-api.js';

const api = new SgToolApi({
    name:    'my-tool',
    version: { api: '0.1.0', ui: '0.1.0', content: '0.1.0' },
    manifest: './manifest.json',
    skills:  { human: './SKILL-human.md', browser: './SKILL-browser.md', api: './SKILL-api.md' },
});
```

### 2. Register methods (wrap existing UI logic)

```js
// Sync method
api.register('getState', () => ({
    prompt: textarea.value,
    model:  modelPicker.getModel(),
}), { async: false });

// Async method — sanitise secrets from logs
api.register('connect', ({ apiKey, model } = {}) => doConnect(apiKey, model), {
    async: true,
    sanitiseParams: p => ({ ...p, apiKey: '••••' }),
    events: ['tool:connected'],
});

// Async method that fires events
api.register('generate', ({ prompt } = {}) => doGenerate(prompt), {
    async: true,
    events: ['tool:generation:started', 'tool:generation:complete', 'tool:generation:error'],
});
```

### 3. Activate (after all registers)

```js
api.activate();  // publishes to window.__tools, fires tool:ready
```

### 4. Emit events from your implementation functions

```js
import { SGA_TOOL } from '/core/sg-tool-api/v0/v0.1/v0.1.0/sg-tool-api-events.js';

// Inside doGenerate():
api._emit(SGA_TOOL.GENERATION_STARTED, { callId, model, prompt });
// ... await LLM response ...
api._emit(SGA_TOOL.GENERATION_COMPLETE, { callId, model, duration });
```

## Add the Dev Panel to Your Tool Page

Drop these three components into the tool page HTML. They auto-bind on `tool:ready`:

```html
<sg-tool-api-console></sg-tool-api-console>
<sg-tool-api-explorer></sg-tool-api-explorer>
<sg-tool-api-manifest></sg-tool-api-manifest>
```

Import the components:
```js
import '/components/tool-api/sg-tool-api-console/v0/v0.1/v0.1.0/sg-tool-api-console.js';
import '/components/tool-api/sg-tool-api-explorer/v0/v0.1/v0.1.0/sg-tool-api-explorer.js';
import '/components/tool-api/sg-tool-api-manifest/v0/v0.1/v0.1.0/sg-tool-api-manifest.js';
```

## Checklist

- [ ] `SgToolApi` constructed with `name`, `version`, `manifest`, `skills`
- [ ] All user-callable actions registered via `api.register()`
- [ ] Secrets sanitised in `sanitiseParams` (apiKey etc.)
- [ ] `api.activate()` called after all registers
- [ ] Standard `SGA_TOOL` events emitted at correct moments
- [ ] Three SKILL files written
- [ ] Dev panel components included in tool page
