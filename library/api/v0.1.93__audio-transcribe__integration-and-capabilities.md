# Audio Transcribe + Live Transcribe — Integration & Capabilities Guide

**Version:** v0.1.93
**Audience:** agents wiring these tools into a **vault-powered website** and/or the **main sgraph.ai website**.
**Tools covered:** `audio-transcribe` **v0.1.24** · `live-transcribe` **v0.1.0** · core module `sg-tts-openrouter` **v0.1.0** (all in `tools/v0/v0.1/v0.1.60/` / `core/`).
**Source of truth:** this guide is code-verified against the branch; cross-check the manifest (`…/audio-transcribe/manifest.json` `api` section) which is authoritative for the JS API.

> **One-line model:** these are **static, client-side, BYOK** tools. They call OpenRouter **directly from the browser** with the user's key. There is **no server**. The vault/website's job is (a) optionally **inject a key**, (b) **embed/host** the page, (c) optionally **read cost / set a spend cap / drive it headlessly**. Everything below is a seam for that.

---

## 1. What exists (two tools, one shared engine)

| Thing | URL (served) | What it is |
|---|---|---|
| **Audio Transcribe** | `/en-gb/audio-transcribe/` | Full tool: record/drop many files (incl. WhatsApp `.opus`), batch transcribe, per-recording **version history + parallel multi-model**, **Live** mode, **Voice** (TTS), **Chat**, Bundle→ZIP, encrypted Send, cost everywhere, provenance panel. |
| **Live Transcribe** | `/en-gb/live-transcribe/` | Minimal "big button" **experience variation** — just Live (press-to-talk → refining transcript + per-segment cost) + a file-drop fallback. **Reuses** audio-transcribe's `api/` modules + the `ui-live` panel (no engine duplication). |
| **`core/sg-tts-openrouter`** | `/core/sg-tts-openrouter/v0/v0.1/v0.1.0/sg-tts-openrouter.js` | **NEW versioned** OpenRouter cloud-TTS engine (importable by vault pages, `*` CORS, like sg-audio-decode). |

Both tools publish the **same `SgToolApi` surface** on `window.__tool` after the `tool:ready` event. Live Transcribe is a strict subset.

## 2. The vault / embedding contract (read this first)

These are the seams the vault-integration brief (v0.33.27) asked for; all are **done in source**:

| Need | Seam | Notes |
|---|---|---|
| **Inject a key** (no paste box) | `await __tool.setApiKey({ apiKey, model? })` | Persists to `localStorage['sg-openrouter-mgmt-key']` + connects. Masked in the dev console. BYOK is the default; this is the "host supplies the SG-API secret" path. |
| **Read state headlessly** | `__tool.getItems()` → **array**; `__tool.getItem({id})` | Authoritative shape is an **array** of serialisable items (no Blob). |
| **Per-transcript cost** | `transcribeItem()` returns `{ …, generationId, usage:{promptTokens,completionTokens,costUsd} }` | Embedder can do its own `GET /api/v1/generation`; the tool also resolves the exact cost itself. |
| **Scriptable chat** (no UI) | `await __tool.ask({ text, model?, context? })` → `{ text, model, generationId, usage }` | Default system prompt = the done transcripts. Drive chat through this, **not** the chat-UI DOM (internal ids may change). |
| **Get synthesised audio** | `synthesize({ …, returnAudio:true })` → `{ …, audioDataUrl }` | base64 WAV over the JS API. Or `addSynthesized()` → queue item. `synthesize` also honours an `{apiKey}` override. |
| **Cap spend** (sponsored key) | `__tool.setSpendCap({ usd })` (or `null` to clear) | Soft cap: transcribe/Live halt with `{code:'budget-cap'}` once known spend ≥ cap. The **vault provides the value**; the tool enforces. |
| **Typed key/quota errors** | rejections carry `{ code, status }` | `key-invalid`(401) · `budget-exceeded`(402) · `key-exhausted`(403) · `rate-limited`(429) — mapped from the HTTP status (no string-matching). |
| **Live in a sandboxed frame** | `startLive()` rejects `{code:'mic-unavailable'}` + emits `at:live:error` | In a null-origin frame `navigator.mediaDevices` is undefined. **Host must grant `allow="microphone"` + a secure context** for capture; otherwise hide Live and use file-drop (Live Transcribe degrades exactly this way). |

**CORS / cross-origin import:** the tool origin answers `Origin: null` with `Access-Control-Allow-Origin: *`, so a vault `blob:`/`srcdoc` frame can `import()` the components (`sg-audio-decode`, `sg-llm-request`, `sg-openrouter-key-stats`, `sg-tts-openrouter`) and run them in-frame. **Do not change CORS headers, module layout, or the components' public shape** — that's a breaking change for embedders.

## 3. Full JS API (window.__tool)

After `tool:ready` (`{ instanceId, tool:'audio-transcribe', version }`). Every registered action returns a **Promise** (even the `async:false` ones). `live-transcribe` implements the **bold** subset.

### Source & queue
- **`addFiles({ files })`** → `{ added:[{id,name,sizeBytes,mimeType}], rejected:[{name,code}] }` — ingest File[]/FileList (incl. `.opus`). *(both)*
- `startRecording({deviceId?,mimeType?})` → `{recording:true,mimeType}` ; `stopRecording()` → `{id,name,sizeBytes,mimeType,durationMs}`
- **`getItems()`** → `[item]` ; **`getItem({id})`** → `item|null` ; `removeItem({id})` ; `clearAll()`
- `loadSample({id})` — built-in test tone (`tone-a`/`tone-b`), no network.

`item = { id, name, sizeBytes, mimeType, durationMs?, origin:'recording'|'file', model, status:'queued'|'transcribing'|'done'|'error', transcript?, error?, errorCode?, generationId?, costUsd?, costPending?, versions:[…] }`

### Models & key
- `listModels()` → `[{id,label,cost,speed,available,default}]` (7 working chat-path models + 2 gated STT). `setModel({model,id?})`.
- **`connect({apiKey,model?})`** ; **`setApiKey({apiKey,model?})`** → `{ok,present,model}` (persists + connects).

### Transcribe
- **`transcribeItem({id,model?})`** → `{id,text,model,latencyMs,vid,generationId,usage}` — rejects typed `{code,status}` on a provider error.
- `transcribeModels({id,models:[]})` → `{id,results:[{vid,model,ok}]}` — **parallel** multi-model, one version each (isolated transport, no cross-talk).
- `cancelItem({id})` → `{cancelled:N}` — **aborts in-flight requests** for an item (kills the upstream fetch). Powers the "Stop"/"Stop all" buttons.
- **`transcribeAll({concurrency?})`** / **`transcribe()`** (alias) — batch, parallel pool (default 4). Emits `at:batch:*`.
- **`getTranscript({id?})`** → one or all transcripts.

### Live (near-realtime)
- **`startLive({intervalMs?})`** → `{live:true,mimeType,intervalMs}` — opens the mic, transcribes only the **new audio per poll (a delta)** every `intervalMs` ms (default 2500; UI offers 1s–6s). Shorter = more responsive, more+smaller (overlapping) requests = more $.
- **`stopLive({finalPass?})`** → `{id,text,durationMs}` — `finalPass` (default `true`) does one **full-quality re-transcription** for a clean saved transcript; `false` keeps the cheaper appended delta text. Adds the take to the queue.
- **Cost model:** each delta is a real billed request (recorded as `state.aux kind:'live'` → counts in the session total + the spend cap). Live text is reassembled **by sequence number** (contiguous prefix), so out-of-order OpenRouter responses never jump ahead. Splitting is **time-based, not silence/VAD**.

### Voice (TTS), chat, cost, bundle, send
- `synthesize({text,mode:'local'|'openrouter',voice?,model?,apiKey?,returnAudio?})` → `{mode,durationMs,sizeBytes,mimeType,generationId?,audioDataUrl?}` ; `addSynthesized({…,name?})` → queue.
- **`ask({text,model?,context?})`** → `{text,model,generationId,usage}` — headless chat over the transcripts.
- **`getCostSummary()`** → `{sessionUsd,sessionPending,perItem:[{id,name,usd,pending,versions}],auxUsd,auxPending}` ; **`setSpendCap({usd})`** → `{cap}`.
- `getExchanges()` → provenance log (last 50 request/response records; audio bytes never included).
- `downloadZip({include:{audio?,transcripts?},items?,name?})` ; `sendViaSgSend({include?,items?,accessToken?,name?})` → `{shareUrl,token}` (needs a live send.sgraph.ai + token).
- `getReleases()` → changelog.

### Events (`AT_EVENTS`, all `at:*`, on `window`; detail includes `instanceId`)
`recording:started/stopped` · `item:added/removed` · `model:changed` · `transcribe:started/progress/complete/error{code}` · **`llm:exchange`** (provenance) · **`live:started{mimeType,intervalMs}` / `live:update{text,elapsedMs,final}` / `live:segment{seq,sizeBytes,elapsedMs,latencyMs,text,final,ok,generationId?,costUsd?,costPending?,delta?}` / `live:stopped{id,text}` / `live:error{error,code?}`** · `batch:started/progress/complete` · `bundle:created` · `send:started/complete/error` · `reset`.

### Error codes (`err.code`)
`not-audio`/`too-large`/`empty`(ingest) · `unknown-item` · `no-model`/`model-unavailable` · `cancelled` · **`budget-cap`** (spend cap) · **`key-invalid`/`budget-exceeded`/`key-exhausted`/`rate-limited`** (provider HTTP status) · `mic-unavailable` (Live in a sandboxed frame) · `no-text`/`no-key`/`tts-http`(TTS) · `send-auth-required` · `llm-error`.

## 4. Component capabilities (what each piece does)

**Reused as-is (do not fork):**
- `core/sg-tool-api` — the `window.__tool` primitive + dev panel (console/explorer/manifest).
- `core/sg-audio` — mic recording. `core/sg-audio-decode` — three-tier never-fail `.opus`/webm → WAV (pass-through → `decodeAudioData` → WASM Opus). `core/sg-wasm-cache` — Cache-API WASM persistence; **vault-safe** (`isCacheApiAvailable()` guards the throwing `typeof caches` in a sandboxed frame).
- `components/llm/sg-llm-request` v0.1.6 + `sg-llm-events` — the OpenRouter fetch + audio wire-format; **forwards HTTP `status`+`bodyError`** on `REQUEST_ERROR` (basis of the typed errors).
- `components/sg-audio-viz` — live waveform. `components/site-header` — banner. `components/openrouter/sg-openrouter-key-stats` — live budget panel (reads `GET /api/v1/key`). `components/send-drop` — encrypted upload. `components/llm/sg-llm-chat-*` — the Chat UI.
- `core/sg-layout` — the fractal panel shell (desktop 2-column / mobile single-stack).

**New / tool-owned:**
- **`core/sg-tts-openrouter`** (versioned) — `synthesizeOpenRouter(text,{apiKey,voice?,model?,fetchImpl?})` → `{blob,durationMs,generationId,transcript}` + `encodeWav`/`base64ToBytes`/`base64ToBlob`/`pcm16ToWav`/`TTS_OPENROUTER_VOICES`/`TTS_OPENROUTER_DEFAULT_MODEL`. Streams `pcm16` (the only streamable format) and wraps it to WAV in-browser.
- Tool-internal: `api/llm-transport.js` (the **isolated per-request transport** — each request its own throwaway bus cell, so parallel/concurrent requests never cross-talk; classifies errors), `api/llm-errors.js` (`classifyLlmError`/`friendlyLlmError`), `api/live.js` (`createLiveSession` — delta capture, seq reassembly, bounded concurrency), `ui/state.js` (queue + version history + `aux` cost accumulator + spend cap).

## 5. Wiring it up

**To the main sgraph.ai website (link/iframe):** both tools are flat static pages — link to `/en-gb/audio-transcribe/` and `/en-gb/live-transcribe/`. They're registered in `tools/…/_common/js/sg-tool-registry.js` `TOOL_SLUGS` under **media**, so the tools directory picks them up automatically. No build step; deploy the folder as-is.

**To a vault-powered website (embed + drive):**
1. Embed the page (or import the components) cross-origin — CORS already allows null-origin.
2. After `tool:ready`, `await __tool.setApiKey({ apiKey })` with the SG-API secret (or let the user paste — BYOK).
3. Optional: `__tool.setSpendCap({ usd })` for a sponsored key; read `__tool.getCostSummary()` / subscribe to `at:live:segment` for running cost.
4. For embedded **Live**, put `allow="microphone"` on the iframe + serve over https; otherwise present the file-drop path.
5. Retrieve results via `getItems()`/`getTranscript()`/`ask()`; retrieve synth audio via `synthesize({returnAudio:true})`.

**Headless smoke (drive-it example):**
```js
await __tool.setApiKey({ apiKey: 'sk-or-…' });
const { added } = await __tool.addFiles({ files });          // .opus ok
const { id }    = added[0];
const r = await __tool.transcribeItem({ id });               // {text, generationId, usage}
const answer = await __tool.ask({ text: 'Summarise in 3 bullets.' });
```

## 6. NOT the tool's job (owned elsewhere — brief these teams separately)

- **DevOps:** promote the current bundle + **bust the CDN cache** (a stale deployed bundle is why the live page can lag source); wire the served-page contract assertions (`tests/playwright/audio-transcribe-live-smoke.js` `[9]` getItems-array, `[10]` TTS-bytes) into the pre-promote gate.
- **Vault / key-budget layer:** the **key source** (minting/distributing the SG-API secret) and the **spend-cap value** for a sponsored key. The BYO/early-adopter-key **UI** is blocked on this.
- **Vault team / Librarian:** guard the unguarded `typeof caches` in `core/vault-cache` (same one-line fix already applied to `sg-wasm-cache`) + a repo-wide storage-guard sweep.
- **Host / embedder:** `allow="microphone"` + secure context for embedded Live.
- **SG-API-secret layer:** finer key-exhaustion sub-codes (expired vs exhausted vs revoked — a 401 can't be split from the status alone; the tool emits the typed bucket + raw status to build on).
