# Tool API Primitive — Real-World Examples

**Parent:** `v0.1.91__tool-api__index.md`
**Date:** 2026-05-07

Two production implementations that show the full pattern in action:
`infographic-gen` (LLM generation pipeline) and `send-receive` (file transfer).
Both are live at `tools.sgraph.ai` and fully scriptable from Playwright or the browser console.

---

## Example 1 — Infographic Generator (LLM Generation)

**Tool:** `infographic-gen` v0.1.37  
**Why it's the reference:** The longest-running JS API implementation with the most complete
SKILL files. Shows headless generation, concurrent calls, system prompt injection, and a full
Playwright smoke test.

### The core loop

```js
// 1. Wait for the tool to be ready (fires once after activate())
await page.waitForFunction(() => window.__tool?.meta.health().status === 'ready');

// 2. Connect with an OpenRouter API key
await page.evaluate(key => window.__tool.connect({ apiKey: key }), process.env.OPENROUTER_API_KEY);

// 3. Generate
const result = await page.evaluate(async () =>
    window.__tool.generate({ prompt: 'A 3-step process flow: Plan → Build → Ship' })
);

// result shape:
// {
//   instanceId:   'infographic-generator:root',
//   callId:       'f3a2b1c0-...',   // UUID per call
//   generationId: 'gen_abc123',     // OpenRouter generation ID
//   model:        'google/gemini-2.0-flash-exp:free',
//   duration:     11.4,             // wall-clock seconds
//   imageSrc:     'data:image/png;base64,...'
// }
```

### Headless mode — no UI tab created

Calling `generate({ renderUI: false })` resolves the Promise and fires all window events
without creating a result tab in the UI. This is the key pattern for CI and agentic use:

```js
const result = await page.evaluate(async () =>
    window.__tool.generate({
        prompt:    'Executive summary: revenue +12%, costs -8%',
        model:     'google/gemini-2.0-flash-exp:free',
        renderUI:  false,   // ← headless: Promise resolves, no UI side-effect
    })
);
```

### System prompt injection

Set once, applies to all subsequent `generate()` calls — no need to embed override
instructions inside every prompt:

```js
await page.evaluate(() => {
    window.__tool.setSystemPrompt(
        'You are a professional infographic designer. ' +
        'Use a dark background, teal accent colour, and output SVG with a 16:9 aspect ratio.'
    );
});

const result = await page.evaluate(async () =>
    window.__tool.generate({ prompt: 'A mind map of machine learning concepts' })
);
```

### Concurrent generation — `callId` correlation

Each `generate()` call gets a `crypto.randomUUID()` callId that threads through the Promise
result, all window events, and `getGenerations()` log. Concurrent calls are fully independent:

```js
const [r1, r2] = await page.evaluate(async () =>
    Promise.all([
        window.__tool.generate({ prompt: 'A mind map of ML',   model: 'openai/gpt-4o' }),
        window.__tool.generate({ prompt: 'A timeline of AI',   model: 'google/gemini-2.0-flash-exp:free' }),
    ])
);
// r1.callId !== r2.callId — no ordering dependency
```

### Generation log (session audit trail)

```js
const log = await page.evaluate(() => window.__tool.getGenerations());
// Ring buffer, newest first, max 50 entries. Each record:
const rec = log[0];
// rec.callId, rec.model, rec.prompt, rec.duration, rec.status
// rec.request.messages  — exact multimodal array sent to the LLM
// rec.response.content  — raw LLM response
// rec.response.promptTokens, rec.response.completionTokens
// rec.response.latencyMs, rec.response.finishReason
```

### Full Playwright smoke test

```js
// playwright-infographic.js
const { chromium } = require('playwright');

(async () => {
    const browser = await chromium.launch();
    const page    = await browser.newPage();
    await page.goto('http://localhost:10063/en-gb/infographic-gen/');

    await page.waitForFunction(() => window.__tool?.meta.health().status === 'ready');

    await page.evaluate(key => window.__tool.connect({ apiKey: key }), process.env.OPENROUTER_API_KEY);

    await page.evaluate(() => {
        window.__tool.setSystemPrompt('Output a dark-background SVG infographic.');
    });

    const result = await page.evaluate(async () =>
        window.__tool.generate({
            prompt:   'A simple 3-step process flow: Plan → Build → Ship',
            model:    'google/gemini-2.0-flash-exp:free',
            renderUI: false,
        })
    );

    if (!result.callId)   throw new Error('Missing callId');
    if (!result.duration) throw new Error('Missing duration');

    const log = await page.evaluate(() => window.__tool.getGenerations(1));
    console.log('Finish reason:', log[0].response?.finishReason);
    console.log('Prompt tokens:', log[0].response?.promptTokens);

    console.log('✓ infographic-gen smoke test passed');
    await browser.close();
})();
```

### Methods reference

| Method | Type | Description |
|--------|------|-------------|
| `connect({ apiKey, model? })` | async | Authenticate with OpenRouter; skip-if-same-key |
| `generate({ prompt?, model?, renderUI? })` | async | Run generation; returns `{ callId, imageSrc, duration, … }` |
| `getState()` | sync | `{ mode, prompt, model, connected, activeGenerations, systemPrompt, … }` |
| `getGenerations(n?)` | sync | Ring buffer of last N request/response records |
| `setSystemPrompt(text)` / `getSystemPrompt()` | sync | Override the system prompt |
| `setPrompt(text)` / `getPrompt()` | sync | Set/read the editor prompt |
| `setModel(id)` / `getModel()` | sync | Switch model |
| `setTemplate(id)` | sync | Load a built-in prompt template |
| `stop()` | sync | Cancel all active generations |

## Example 2 — Send / Receive (File Transfer)

**Tool:** `send-receive` v0.1.49  
**Why it's notable:** Wraps the full SG/Send upload/download stack behind a clean JS API.
Shows token-based authentication, typed file operations, round-trip testing, and folder
zipping — all scriptable from Playwright.

### Setup

```js
await page.goto('https://dev.tools.sgraph.ai/en-gb/send-receive/');
await page.waitForFunction(() => window.__tool?.meta?.health?.().status === 'ok');

// Authenticate
await page.evaluate(token => window.__tool.setAccessToken(token), process.env.SG_SEND_TOKEN);
```

### Send a file

```js
const result = await page.evaluate(async () => {
    const content = new Uint8Array([72, 101, 108, 108, 111]); // "Hello"
    const file    = new File([content], 'hello.txt', { type: 'text/plain' });
    return window.__tool.sendFile(file);
});
// { token: 'brave-apple-0742', transferId: '1a2b3c4d5e6f', url: 'https://send.sgraph.ai/...' }
```

### Send text directly

```js
const { token } = await page.evaluate(async () =>
    window.__tool.sendText('Hello, world!', { filename: 'message.txt' })
);
```

### Send a folder (auto-zipped)

```js
const result = await page.evaluate(async () => {
    const files = [
        new File(['# README'], 'README.md'),
        new File(['console.log("hi")'], 'index.js'),
    ];
    return window.__tool.sendFolder(files, { filename: 'project.zip' });
});
// Zips all files and uploads as a single token
```

### Receive a file

```js
const received = await page.evaluate(async (token) => {
    const result = await window.__tool.receiveFile(token);
    const text   = await result.blob.text();
    URL.revokeObjectURL(result.objectUrl);
    return { filename: result.filename, text };
}, 'brave-apple-0742');
```

### Round-trip test

```js
// Send
const { token } = await page.evaluate(async (accessToken) => {
    await window.__tool.setAccessToken(accessToken);
    return window.__tool.sendText('round-trip test', { filename: 'test.txt' });
}, process.env.SG_SEND_TOKEN);

// Receive (in the same page or a different browser — token is shareable)
const text = await page.evaluate(t => window.__tool.receiveText(t), token);
console.assert(text === 'round-trip test');
```

### Transfer history

```js
const history = await page.evaluate(() => window.__tool.getHistory());
// [{ type: 'sent'|'received', token, transferId, url?, filename?, timestamp }]
```

### Full Playwright smoke test

```js
// playwright-send-receive.js
import { test, expect } from '@playwright/test';

const TOOL_URL  = 'https://dev.tools.sgraph.ai/en-gb/send-receive/';
const API_TOKEN = process.env.SG_SEND_TOKEN ?? '';

test('window.__tool is live', async ({ page }) => {
    await page.goto(TOOL_URL);
    await page.waitForFunction(() => !!window.__tool?.meta);
    const health = await page.evaluate(() => window.__tool.meta.health());
    expect(health.status).toBe('ok');
});

test('all 11 methods present', async ({ page }) => {
    await page.goto(TOOL_URL);
    await page.waitForFunction(() => !!window.__tool?.meta);
    const methods = await page.evaluate(() => window.__tool.meta.getMethods());
    for (const m of ['sendFile','sendText','sendFolder','receiveFile',
                     'receiveText','receiveFolder','getHistory','clearHistory',
                     'getState','setToken','setAccessToken']) {
        expect(methods).toContain(m);
    }
});

test('manifest has api section', async ({ page }) => {
    await page.goto(TOOL_URL);
    await page.waitForFunction(() => !!window.__tool?.meta);
    const manifest = await page.evaluate(() => window.__tool.meta.getManifest());
    expect(manifest.api?.version).toBeTruthy();
    expect(manifest.api?.actions?.sendFile).toBeTruthy();
});

test.skip(!API_TOKEN, 'send round-trip (requires access token)', async ({ page }) => {
    await page.goto(TOOL_URL);
    await page.waitForFunction(() => !!window.__tool?.meta);
    await page.evaluate(t => window.__tool.setAccessToken(t), API_TOKEN);

    const { token } = await page.evaluate(() =>
        window.__tool.sendText('Playwright round-trip', { filename: 'pw-test.txt' })
    );
    expect(token).toMatch(/^[a-z]+-[a-z]+-\d{4}$/);

    const text = await page.evaluate(t => window.__tool.receiveText(t), token);
    expect(text).toBe('Playwright round-trip');
});
```

### Methods reference

| Method | Type | Description |
|--------|------|-------------|
| `sendFile(file, opts?)` | async | Upload a `File` or `Blob`; returns `{ token, transferId, url }` |
| `sendText(text, opts?)` | async | Upload a plain-text string; returns `{ token, transferId, url }` |
| `sendFolder(files[], opts?)` | async | Zip an array of `File` objects and upload as one token |
| `receiveFile(token)` | async | Download and return `{ filename, blob, objectUrl, token, transferId }` |
| `receiveText(token)` | async | Download and return the content as a `string` |
| `receiveFolder(token)` | async | Download and unzip; returns `{ files: [{ filename, blob }] }` |
| `getHistory()` | sync | Array of sent/received transfer records for this session |
| `clearHistory()` | sync | Wipe the in-memory transfer log |
| `getState()` | sync | `{ hasAccessToken, sendUrl, history }` |
| `setToken(token)` | sync | Set the receive token in the UI input field |
| `setAccessToken(token)` | sync | Set the upload access token |

## Discovery API (same on every tool)

These meta methods are available on every `window.__tool` instance — no per-tool wiring:

```js
window.__tool.meta.health();
// → { status: 'ready'|'ok', instanceId, methodCount, methods: [...] }

window.__tool.meta.getMethods();
// → ['method1', 'method2', ...]

window.__tool.meta.getVersion();
// → { api: '0.1.0', ui: '0.1.49', content: '0.1.0' }

await window.__tool.meta.getManifest();
// → full manifest.json including api.actions schema

window.__tool.meta.getLog();
// → last 500 method call records with params, result, duration

await window.__tool.meta.getSkills();
// → { human: '# ...', browser: '# ...', api: '# ...' }
// Fetches all three SKILL files at runtime — used by LLM agents for self-documentation
```

## Patterns Summary

| Pattern | How it's done |
|---------|---------------|
| Wait for API ready | `waitForFunction(() => window.__tool?.meta.health().status === 'ready')` |
| Headless LLM generation | `generate({ renderUI: false })` |
| Correlate concurrent calls | `callId` UUID returned in Promise result and all window events |
| Inspect raw LLM request | `getGenerations()[0].request.messages` |
| Override system prompt | `setSystemPrompt(text)` before `generate()` |
| Cancel in-flight generation | `stop()` |
| Auth before file ops | `setAccessToken(token)` then `sendFile()` / `receiveFile()` |
| Send multiple files atomically | `sendFolder([file1, file2], { filename: 'bundle.zip' })` |
| Tool self-description for agents | `meta.getSkills()` fetches all 3 SKILL files at runtime |
| Zero-setup dev panel | Every tool with `activate()` gets console/explorer/manifest panel for free |
