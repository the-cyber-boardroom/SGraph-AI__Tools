# Tool API Primitive — Reference

**Parent:** `v0.1.91__tool-api__index.md`

---

## SgToolApi Constructor

```js
import { SgToolApi } from '/core/sg-tool-api/v0/v0.1/v0.1.0/sg-tool-api.js';

const api = new SgToolApi({
    name:     'my-tool',           // required — registry key
    version:  { api: '0.1.0', ui: '0.1.0', content: '0.1.0' },
    panelId:  'root',              // optional — auto-detected from sg-layout DOM
    manifest: './manifest.json',   // optional — URL to manifest.json
    skills:   {                    // optional — URLs to SKILL files
        human:   './SKILL-human.md',
        browser: './SKILL-browser.md',
        api:     './SKILL-api.md',
    },
});
```

## Instance Methods

| Method | Signature | Effect |
|--------|-----------|--------|
| `register` | `(name, fn, opts?) → this` | Register a callable method. Chainable. |
| `activate` | `() → this` | Publish to `window.__tools`, fire `tool:ready`. |
| `[methodName]` | `(params?) → Promise<*>` | Call any registered method directly. |

### register() opts

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `async` | boolean | true | Whether fn returns a Promise |
| `events` | string[] | [] | Event names this method may emit |
| `environment` | string[] | ['browser'] | Supported runtime environments |
| `sanitiseParams` | fn | undefined | Strip secrets before logging (e.g. mask apiKey) |

## meta API

Available on any `SgToolApi` instance as `api.meta.*`:

| Method | Returns | Description |
|--------|---------|-------------|
| `getMethods()` | string[] | Registered method names |
| `getVersion()` | object | `{ api, ui, content }` |
| `getManifest()` | Promise<object> | manifest.json (fetched + cached) or synthesised |
| `getSkills()` | Promise<object> | `{ human, browser, api }` SKILL file contents |
| `getEvents()` | string[] | All event names across registered methods |
| `health()` | object | `{ status, instanceId, methodCount, methods, logEntries }` |
| `getLog()` | object[] | Last 500 invocation records (params, result, duration, error) |

## Registry (window)

| Global | Description |
|--------|-------------|
| `window.__tool` | Convenience alias — only set when exactly one tool instance exists |
| `window.__tools[instanceId]` | Direct access by `'{name}:{panelId}'` |
| `window.__tool_registry.find(name)` | First instance of a named tool |
| `window.__tool_registry.findAll(name)` | All instances of a named tool |
| `window.__tool_registry.findById(instanceId)` | Exact instance lookup |
| `window.__tool_registry.list()` | All registered instances |
| `window.SGA_TOOL` | Frozen event name constants |

## Standard Events (SGA_TOOL constants)

All dispatched on `window`. All include `instanceId` in detail.

| Constant | Event name | When |
|----------|------------|------|
| `TOOL_READY` | `tool:ready` | After `activate()` |
| `TOOL_CONNECTED` | `tool:connected` | External service connected |
| `TOOL_DISCONNECTED` | `tool:disconnected` | Connection lost |
| `GENERATION_STARTED` | `tool:generation:started` | LLM request dispatched |
| `GENERATION_COMPLETE` | `tool:generation:complete` | LLM response received |
| `GENERATION_ERROR` | `tool:generation:error` | Request failed |
| `GENERATION_CANCELLED` | `tool:generation:cancelled` | User or `stop()` cancelled |

Tools may define additional events beyond these standard ones.
