## 🔑 Account panel (left)

Top: client ID input → Connect / Sign-out.

After connecting, the **channel card** shows:
- Channel banner image (64 px backdrop with gradient fade)
- Avatar (lifts –28 px to overlap the banner)
- Channel title (e.g. "Dinis Cruz - SGraphAI - GenAI and Development")
- `@handle` (e.g. `@dinis-cruz`)
- Stats: `87 videos · 24 subscribers · 9 516 views`
- Joined date · Country (e.g. "Joined Mar 2018  ·  GB")
- Description — clamped to 2 lines with **more** / **less** toggle (toggle hides itself if the text fits)
- Topic chips (max 6, e.g. "Technology", "Software engineering")
- Links: **View on YouTube ↗** · **Open Studio ↗**

Below the channel card: **📈 Last 28 days** analytics summary (only if `yt-analytics.readonly` granted):
- 4 tiles: Views · Watch hrs · Subs gained (net) · Likes
- Date range printed in mono font

If analytics scope wasn't granted: an inline orange notice tells you to sign out + reconnect.

## 📋 My Videos tab

Header: "My YouTube Uploads · 50 of 89" + Refresh button.

Toolbar:
- **Filter** input — text matches title + description on already-loaded items (no API call)
- **Sort** dropdown — Newest / Oldest / Most viewed / Longest / Shortest / Title A→Z

Each row: thumbnail (96×54) · title · sub-line (date · `4:13` duration · `1.2K views`) · privacy badge (`public` / `unlisted` / `private`).

**Click a row** → opens an editor tab in the right stack (or focuses the existing tab if already open).

Bottom: **Load more** button — appears when there are more pages to fetch (1 unit per page).

Auto-refreshes when:
- An upload completes (so the new video appears)
- You delete a video (via the SDK; UI delete is disabled)

---

## ⬆ Upload tab

Compact 2-column form. After picking a file, the dropzone collapses into a one-line chip showing `🎬 filename.mp4 · 25 MB · ✕`.

Title auto-fills from the filename if you haven't typed anything. Privacy defaults to **Unlisted**.

Click **Upload to YouTube** → progress bar fills as bytes go directly to YouTube.

On success:
- Upload button hides
- Big success card with `✓` icon, the YouTube URL, and a Copy button
- **↺ Upload another** ghost button appears — clicking it resets the entire form for the next upload

Drop a file from a sibling tool (e.g. video-recorder's "Send to YouTube" button) → arrives here pre-filled with file + title. Inline notice: "Received from video-recorder. Ready to upload."

---

## 📂 Playlists tab

Header: "My YouTube Playlists · 6 playlists" + Refresh.

Each row: thumbnail · title · `12 videos` count · expand chevron `▸`.

Click a row → expands to show that playlist's videos:
- Expanded card has teal border + soft glow
- Header gets tinted teal background
- Item list is inset (left indent + teal accent bar)
- Capped at `max-height: 360px` with its own scrollbar — multiple expanded playlists co-exist without crowding
- Each inner item: tiny thumbnail (80×45) + title

Click an inner item → opens an editor tab for that video, same flow as clicking from My Videos.

Lazy: each playlist's items are loaded on first expand (1 quota unit) and cached. Re-expanding doesn't re-fetch.

## ✎ Editor tabs (per-video)

Opened by clicking a row. Multiple can be open at once. Closeable via the `×` on the tab.

**Header** — thumbnail, title, video id (mono), three links + Preview button:
- **Open on YouTube ↗**
- **Open in Studio ↗**
- **⬇ Download (Studio)** — same URL as Studio link; tooltip explains "use ⋮ → Download on the Studio page" (the public API doesn't expose original-blob downloads)
- **▶ Preview** toggle — lazily loads `youtube.com/embed/{id}` iframe inline. Click again to hide.

Privacy badge top-right reflects the current value.

**Form**:
- Title (max 100), Description (5000), Tags (comma-separated), Privacy (Private / Unlisted / Public)
- **Save changes** — on success, the button briefly flashes brighter teal + "✓ Saved" for ~1.4 s
- **Reset** — reverts to the last loaded values

**Replace thumbnail** row — image picker (JPG/PNG, ≤ 2 MB) → Upload thumbnail.

**Playlists section** — checkboxes for each of your playlists, ticked = video is in. Tick/untick toggles add/remove with optimistic UI (rolls back on failure). Refresh button re-fetches the membership.

**📈 Analytics section** (only if analytics scope granted):
- Window selector: 7 / 28 / 90 / 365 days
- 6 metric tiles: Views · Watch hrs · Avg view (m:ss) · Avg % · Subs gained · Likes
- **Audience retention chart** — SVG line + gradient area, 0 % → 100 % elapsed axis. Shows "not enough views yet" gracefully when YouTube returns empty for low-view videos.

## ▸ JS API dev pane (footer bar)

Click the bar at the bottom — opens a 280 px panel with four tabs:

| Tab | What it shows |
|---|---|
| **⚡ Explorer** | Auto-generated UI listing every registered method. Click a method to call it with a JSON-edited param object. Returns + events stream below. |
| **> Console** | A live JS console scoped to `window.__tool['youtube-editor']`. Tab-completes method names. |
| **📋 Manifest** | The full `manifest.json` rendered as a tree. Useful for seeing the dependency graph and event taxonomy. |
| **📄 Skills** | `SKILL-human.md` / `SKILL-browser.md` / `SKILL-api.md` rendered inline. The same files Claude Agents read to learn the tool. |

The footer bar shows: `▶ YouTube Editor  v0.1.0  LIVE  24 deps  ▸ JS API`.

## Recorder hand-off (the workflow)

1. Open the **video-recorder** tool (`/en-gb/video-recorder/`).
2. Record (camera / screen / both / audio modes — 7 combinations).
3. After stopping: in the recording's tab, scroll to **Send to YouTube**.
4. Click **▶ Send to YouTube Editor**.
5. New tab opens with the editor; Upload tab is auto-focused; the recording is pre-filled as the file; title is suggested from the recording name.
6. Set privacy + click Upload.

End-to-end record-to-publish without leaving tools.sgraph.ai.
