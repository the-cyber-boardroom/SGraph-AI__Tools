# Brief — Video Review · 4/5 API Surface

`window.__tool` after `tool:ready`, the mandated SgToolApi pattern. Every action
returns a Promise. **PROPOSED — does not exist yet.**

The shared workspace actions (`getPairs`, `setNotes`, `movePair`, `insertPair`,
`askPair`, `askSession`, `buildDocument`, `downloadPdf`, `downloadZip`,
`saveToVault`, …) come from `core/sg-review-pairs` and behave **exactly** as they
do in `narrated-review` v0.1.1 — same names, same shapes. They are listed in the
manifest but not re-specified here; this part covers only what is new.

---

## Source & processing (9)

- `addVideo({ file })` → `{ durationMs, sizeBytes, width, height, hasAudio, codec }`
  — probes via `core/video getVideoInfo`. Rejects `{code:'not-video'}`.
- `estimate()` → `{ segments, pairsAfterGrouping, transcribeUsd, refineUsd, totalUsd }`
  — a *pre-flight* number from duration and settings, shown before anything is
  spent. Deliberately an action, not a UI-only calculation, so an agent sees the
  bill before committing.
- `setProcessConfig({ frameStepMs?, leadMs?, lagMs?, group?, refine?, vad?, sttMode? })`
  → the merged config. `sttMode: 'openrouter' | 'local-whisper'`.
- `process({ stages? })` → `{ pairs, segments, durationMs, costUsd }` — the whole
  pipeline. `stages` re-runs part of it (`['frames','group']`), which is what the
  UI's per-step re-run buttons call.
- `extractAudio()` / `segment()` / `transcribeSegments({concurrency?})` /
  `chooseFrames()` / `groupSegments()` — the individual stages, each idempotent
  and separately callable. `process()` is their composition; agents can drive
  either level.

## Frames (5)

- `getCandidates({ id })` → `[{ t, index, score, chosen }]` — every sampled frame
  for a pair, with its stability score.
- `getCandidateImage({ id, index })` → `{ dataUrl }`.
- `setFrame({ id, index })` — adopt a candidate as the pair's frame. One click in
  the filmstrip; no recomputation.
- `setFrameAt({ id, t })` → `{ index }` — grab an arbitrary timestamp (the slider
  case: "not any of these, *this* moment").
- `refineFrames({ ids?, model? })` → `{ refined, changed, costUsd }` — the opt-in
  model pass: candidates + segment text → the model picks. Reports how many it
  actually changed, so its value is measurable rather than assumed.

## Segments (3)

- `getSegments()` → `[{ index, tStart, tEnd, text, pairId }]` — the transcript
  underneath the pairs, still intact after grouping.
- `splitPair({ id, atSegment })` → `{ ids }` — undo a grouping decision.
- `mergePairs({ ids })` → `{ id }` — group manually where the metric was too shy.

## Events (`VR_EVENTS`, all `vr:*`) — plus the shared `nr`-shaped set re-emitted under `vr:`

`vr:video:loaded {durationMs,width,height,hasAudio}` ·
`vr:stage:started {stage}` / `vr:stage:progress {stage,done,total}` /
`vr:stage:complete {stage,ms}` / `vr:stage:error {stage,code}` ·
`vr:segments:ready {count}` · `vr:frames:ready {count}` ·
`vr:group:applied {before,after}` · `vr:frame:changed {id,index,by:'user'|'model'}` ·
`vr:refine:complete {refined,changed,costUsd}` ·
then the shared `vr:pair:*`, `vr:chat:*`, `vr:document:built`, `vr:pdf:created`,
`vr:vault:*`, `vr:bundle:created`.

## Error codes

`not-video` · `no-audio-stream` · `audio-too-large` · `ffmpeg-unavailable`
(WASM blocked) · `decode-failed` · `frame-seek-failed` · `unknown-pair` ·
`no-key` · `budget-cap` · the typed provider set (`key-invalid` /
`budget-exceeded` / `key-exhausted` / `rate-limited`) · `cancelled`

## Storage keys

| Key | What | Shared with |
|---|---|---|
| `sg-openrouter-mgmt-key` | BYOK key | every media tool |
| `vr-config` | frame step, lead/lag, grouping, refine, VAD, stt mode | this tool |

Video, frames and audio are **in memory only** — never localStorage, never a server.

## What an agent run looks like

```js
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;
await t.setApiKey({ apiKey: 'sk-or-…' });

await t.addVideo({ file });                       // probe only, nothing spent
console.log(await t.estimate());                  // see the bill first
await t.setSpendCap({ usd: 1.00 });
await t.setProcessConfig({ group: true, refine: false });

await t.process();                                // audio → segments → text → frames → group

// The artefact is now the same shape narrated-review produces.
const pairs = await t.getPairs();
await t.setFrame({ id: pairs[3].id, index: 6 });  // wrong frame → one click
await t.askSession({ text: 'Add a note to any capture showing an error state.' });
const { markdown } = await t.buildDocument();
await t.downloadPdf();
await t.saveToVault({ vaultId, passphrase, includeAudio: false });
```

The point of the last five lines: **they are identical to the sibling tool's.**
Once pairs exist, an agent does not need to know which tool made them.
