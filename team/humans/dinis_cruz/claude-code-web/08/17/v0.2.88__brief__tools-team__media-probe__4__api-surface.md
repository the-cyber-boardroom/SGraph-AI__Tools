# Brief — Media Probe · 4/5 API Surface

`window.__tool` after `tool:ready`, the mandated SgToolApi pattern. Every action
returns a Promise. **PROPOSED — does not exist yet.**

Design rule inherited from `narrated-review` v0.1.5: **the machine-readable shape
is the product, not an afterthought.** An agent asked for `moments[]` there
because the export made it parse markdown headings. This tool's whole output is
data, so its JSON shape is the primary interface and the plots are one view of it.

---

## Actions

### Loading

| Action | Returns | Note |
|---|---|---|
| `loadVideo({ file })` | `{ durationMs, width, height, hasAudio, name, size }` | no gesture needed; recovers duration from a stream-recorded WebM by seeking past the end (the fix in `nr-frames.js`) |
| `getStatus()` | `{ status, source, progress, lanes: { audio, frames, scenes, align }, ffmpegLoaded }` | `status`: `idle｜loading｜analysing｜ready` |

### Analysis (each idempotent, each independently runnable)

| Action | Returns |
|---|---|
| `analyseAudio({ frameMs = 20 })` | `{ frames, floor, speech, bimodal, histogram, flatness }` |
| `analyseFrames({ coarseFps = 1, fineFps = 10, twoPass = true })` | `{ samples, metrics: { meanAbs, blockMax, edgeDiff, histDist } }` |
| `findGaps({ thresholds: [] })` | `{ perThreshold: [{ threshold, gaps: [{ tMs, durationMs }], populations }] }` |
| `findScenes({ metric = 'blockMax', threshold })` | `{ scenes: [{ at, metric, value, durationMs }] }` |
| `alignSignals({})` | `{ deltas: [], median, p10, p90, correlation, suggestedLeadMs, suggestedLagMs }` |
| `replaySegmentation({ silenceThreshold, speechThreshold, endpointMs, maxUtteranceMs })` | `{ segments, capped, cappedRatio }` — runs the REAL `createVad` |
| `analyseAll({})` | the whole `probe` object below |

### The recommendation

| Action | Returns |
|---|---|
| `plan({ strategy })` | the `plan` shape (part 3 §5). `strategy` forces one instead of auto-selecting |
| `estimateCost({ captures })` | `{ transcribeUsd, cleanUsd, totalUsd, basis }` — `basis` names the session the per-capture constants came from |
| `compare({})` | `{ today: {...}, plan: {...}, delta: {...} }` for the compare table |

### FFmpeg lane (optional)

| Action | Returns |
|---|---|
| `runFfmpegLane({ what: 'silence'｜'scene'｜'loudness' })` | `{ rows, parsed, raw }` — `raw` is the retained stderr so a parse failure is diagnosable |
| `ffmpegAvailable()` | `{ loaded, wasmSupported }` |

### Output

| Action | Returns |
|---|---|
| `getProbe()` | the full `probe` object |
| `downloadProbe({ format: 'json'｜'csv'｜'zip' })` | `{ name, bytes }` |
| `getFindings()` | `{ markdown }` — a short written verdict (see below) |
| `getSceneThumb({ at })` | `{ dataUrl }` |
| `reset()` | `{ ok: true }` |

## The `probe` object — the machine-readable product

```js
{
  schema: { name: 'media-probe/probe', version: 1 },
  source: { name, size, durationMs, width, height, hasAudio },
  config: { frameMs, coarseFps, fineFps, signatureRaster: '32x18', blockGrid: '8x8' },

  audio: {
    frameMs: 20,
    floor: 0.041,            // p20 of framewise RMS — the noise floor estimate
    speech: 0.092,           // p90
    bimodal: true,           // are the two modes actually separable?
    dbfs: { floor: -27.7, speech: -20.7 },
    histogram: [{ bin, count }],
    flatness: { floorMedian, speechMedian },   // room tone is narrow-band, speech is not
    // Every candidate threshold, evaluated at once — Decision 4.
    thresholds: [{ value: 0.01, gaps: 3,  topicGaps: 0, capped: 8 },
                 { value: 0.056, gaps: 47, topicGaps: 11, capped: 0 }],
  },

  gaps: { all: [{ tMs, durationMs }],
          populations: { word: {count, medianMs}, sentence: {...}, topic: {...} } },

  frames: {
    sampleMs: [0, 1000, 2000, ...],
    metrics: { meanAbs: [], blockMax: [], edgeDiff: [], histDist: [] },
    p95: { meanAbs, blockMax, edgeDiff, histDist },      // per-metric, per-recording
  },

  scenes: [{ at, metric, value, durationMs, settledAfterMs }],

  align: { deltas: [], median: 900, p10: -400, p90: 2600, correlation: 0.72,
           suggestedLeadMs: 2600, suggestedLagMs: 500 },

  plan: { strategy, reason, cuts: [], shots: [], estimate: {}, warnings: [] },

  // What was NOT measured, and why. Present even when empty.
  gaps_in_analysis: [{ code: 'ffmpeg-not-run', message: '...' }],
}
```

**`thresholds[]` is the heart of it.** One row per candidate silence threshold with
the resulting gap count, topic-gap count and `capped` count. That single table
would have made the v0.1.4 failure obvious in one glance: `0.01 → topicGaps: 0,
capped: 8`.

**`gaps_in_analysis` is not decoration.** A consumer must be able to tell "no
scenes found" from "scene detection never ran". Conflating those is the failure
mode this whole pack exists to prevent, so the shape makes it impossible to
express by accident.

## `getFindings()` — the verdict in words

The probe should be readable by an agent *and* by a person in a hurry, so it
emits a short markdown verdict alongside the numbers:

```markdown
## Media probe — RiskMandate MVP Graph Browser (4:21)

**Audio-led segmentation will NOT work on this recording at the default threshold.**

- Noise floor sits at RMS 0.041 (−27.7 dBFS). The old fixed threshold of 0.01 is
  *below the floor*, so no frame counts as silence and every segment force-cuts at
  the 30 s limit — 8 of 9 did.
- At the calibrated threshold (0.056) there are 47 gaps, 11 of them over 1000 ms.
  That is a usable topic-gap population, so **audio-led** is viable after all.
- Scene changes: 14, median scene 17 s. `blockMax` separates them cleanly;
  `meanAbs` misses 4 (a panel opening over a static page).
- The picture leads the words by a median of 900 ms (p10 −400, p90 +2600), so the
  current 2500/1200 window is about right but slightly tight on the lag side.

**Recommendation:** audio-led at 0.056, 6 captures instead of 9.
Estimated $0.28 vs $0.43 — and no sentence split mid-clause.
```

Those illustrative numbers are **invented for shape**; only the floor/threshold and
the cost figures come from the real session. Phase 0 replaces the rest with
measurements.

## Events

| Event | When | Detail |
|---|---|---|
| `mp:source:loaded` | a video is attached | `{ name, durationMs, width, height, hasAudio }` |
| `mp:analyse:started` | a lane begins | `{ lane }` |
| `mp:analyse:progress` | during a lane | `{ lane, done, total, pass }` |
| `mp:analyse:complete` | a lane ends | `{ lane, summary }` |
| `mp:threshold:changed` | the user drags a threshold | `{ value, segments, capped }` |
| `mp:plan:ready` | a plan is computed | `{ strategy, cuts, captures, estimateUsd }` |
| `mp:warning` | an analysis limit was hit | `{ code, message }` |
| `mp:ffmpeg:loading` / `mp:ffmpeg:ready` | the WASM lane | `{ ratio }` / `{}` |
| `mp:reset` | cleared | `{}` |

## Error codes

`bad-params` · `not-video` (no decodable picture — HEVC `.mov` without FFmpeg) ·
`not-audio` (no audio track) · `no-source` (analysis before `loadVideo`) ·
`ffmpeg-unavailable` · `ffmpeg-parse` (ran but produced nothing parsable —
deliberately distinct from "found nothing") · `cancelled`

## Headless run

```js
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;
await t.loadVideo({ file });
const probe = await t.analyseAll({});
const plan  = await t.plan({});
// The assertion that matters: no arbitrary boundaries.
console.assert(plan.strategy !== 'none');
console.assert(plan.cuts.every(c => c.evidence));
```

No gestures anywhere — the probe is fully drivable by an agent, which is the point:
an agent handed a recording should be able to answer "will this segment cleanly?"
before spending anything.
