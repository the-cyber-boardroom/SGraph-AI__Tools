# Brief — Narrated Review · 4/5 API Surface

Registered on `window.__tool` after `tool:ready`, the mandated SgToolApi pattern. Every action returns a Promise. **PROPOSED — does not exist yet.**

---

## Actions

**Session (5)**
- `startSession({ vad?, cleanup? })` → `{ sessionId, screen:{width,height}, mimeType }` — must run in a user gesture (screen picker + mic). `cleanup: 'grounded'|'text-only'|'off'` (default `grounded`).
- `markMoment()` → `{ id, seq, tPress }` — the keypress action itself; screenshot + boundary snap. Rejects `{code:'no-session'}`.
- `endSession()` → `{ pairs, durationMs, takeSizeBytes }` — finalises the take, closes the last segment, starts the cleanup queue.
- `getSession()` → serialisable session (no Blobs; screenshots referenced by pair id, fetched via `getPairImage`).
- `reset()` — discard everything, back to idle.

**Headless import (3)** — the same pipeline with no live capture, so agents and Playwright can drive it with zero gestures:
- `addRecording({ file })` → `{ durationMs }` — an audio file becomes the take.
- `markAt({ t, image? })` → `{ id, seq }` — plant a marker at `t` ms; optional image File/Blob stands in for the screenshot.
- `transcribeAll({ concurrency? })` → `{ done, failed }` — run the parallel lane over all bounded pairs.

**Pairs (7)**
- `getPairs()` → `[pair]` (serialisable; `raw.text`, `clean.text`, marks, costs, bounds).
- `getPair({ id })` / `getPairImage({ id })` → pair | `{ dataUrl }`.
- `setBoundary({ id, tStart?, tEnd? })` — review-pass drag; re-slices, flags the pair stale.
- `setText({ id, text })` — edits **clean** text only; raw is immutable by contract.
- `removePair({ id })` ; `retranscribePair({ id, model? })` → refreshed `raw` (previous raw kept in the pair's version history, the audio-transcribe `versions[]` discipline).

**Cleanup (3)**
- `cleanPair({ id, model? })` → `{ cleanText, marks }` — re-runs one pair against the *current* rolling summary.
- `cleanAll()` → `{ done, failed }` — the sequential lane, seq order.
- `getSummary()` → `{ summary, updatedAtSeq }`.

**Document & export (4)**
- `buildDocument()` → `{ markdown, images:[{name, pairId}] }` — pure assembly, no network.
- `getDocument()` → last built `{ markdown }`.
- `downloadZip({ include? })` — `review.md` + `images/` + `audio/` (per-segment WAVs + take) + `raw/` + `session.json`; emits `nr:bundle:created`.
- `sendViaSgSend({ accessToken? })` → `{ shareUrl, token }` — send-drop path.

**Key & cost (4)**
- `setApiKey({ apiKey, model? })` (sanitised in the exec log) ; `listModels()` — from `core/sg-transcribe` `audio-models.js` for STT + curated multimodal list for cleanup.
- `getCostSummary()` → `{ sessionUsd, perPair:[{id, transcribeUsd, cleanUsd}], pending }` ; `setSpendCap({ usd })` — cap spans both lanes.

**Meta (2)** — `getStatus()` ; `health()` (via `api.meta`).

## Window events (`NR_EVENTS`, all `nr:*` except the shared `tool:ready`; detail carries `instanceId`) — frozen once shipped

`nr:session:started {screen, mimeType}` · `nr:mark {id, seq, tPress}` · `nr:suggestion {t}` (VAD tick) · `nr:pair:added/updated/removed {id}` · `nr:transcribe:started/complete/error {id, code?}` · `nr:session:ended {pairs, durationMs}` · `nr:clean:started/complete/error {id, marks?, code?}` · `nr:summary:updated {length}` · `nr:document:built {pairs, bytes}` · `nr:bundle:created {zipSize, name}` · `nr:send:started/complete/error` · `nr:reset`

## Storage keys

| Key | What | Shared with |
|---|---|---|
| `sg-openrouter-mgmt-key` | BYOK OpenRouter key | audio-transcribe, live-transcribe, video-publisher, infographic-gen |
| `nr-config` | marker lookback, VAD tuning, models, cleanup mode, spend cap | this tool only |

Session content (pairs, audio, screenshots) is **never** in localStorage — in-memory only (Decision 9).

## Error codes

`no-session` · `screen-unavailable` / `mic-unavailable` (sandboxed frame / permission — the audio-transcribe precedent) · `unknown-pair` · `not-audio` (import) · `no-key` · `budget-cap` · `key-invalid` / `budget-exceeded` / `key-exhausted` / `rate-limited` (typed HTTP mapping from `sg-transcribe`) · `clean-parse` (cleanup JSON invalid — raw stands, pair flagged) · `cancelled`

## What an agent run looks like

```js
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;
await t.setApiKey({ apiKey: 'sk-or-…' });               // or already in localStorage

// Headless: an existing narration file + markers where the moments were
await t.addRecording({ file: narrationWav });
for (const ms of [3200, 41000, 96500]) await t.markAt({ t: ms });
await t.transcribeAll();                                 // parallel lane → raw on each pair
await t.cleanAll();                                      // sequential lane → clean + marks
                                                         // (screenshot-grounded when images given)
const { markdown, images } = await t.buildDocument();
// markdown: one section per pair — heading, image ref, clean text,
// [unsure] footnotes, raw appendix. This artefact IS the model interface.
await t.downloadZip();                                   // or sendViaSgSend()
console.log(await t.getCostSummary());                   // both lanes, per pair + roll-up
```

Live capture differs only at the top: `startSession()` (gesture), real keypresses become `markMoment()`, `endSession()` replaces the import block. SKILL-browser documents that `startSession` cannot be driven from `evaluate()` — Playwright must `page.click('#nr-share')` and fake the picker with `--auto-select-desktop-capture-source`.
