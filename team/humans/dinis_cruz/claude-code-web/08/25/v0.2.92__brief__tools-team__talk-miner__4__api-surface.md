# Brief — Talk Miner · 4/5 API Surface

`window.__tool` after `tool:ready`, the mandated SgToolApi pattern. Every action
returns a Promise. **PROPOSED — does not exist yet.**

The surface splits the way the code does (part 3 §1): the **ingest** actions land
on `narrated-review`, the **corpus** actions on `talk-miner`. Both are documented
here because the boundary between them is the design.

---

## Part A — added to `narrated-review` (the fourth ingest path)

| Action | Returns | Note |
|---|---|---|
| `connectYouTube({ clientId? })` | `Promise<{ signedIn, channel, scopes }>` | reuses the existing OAuth flow. Asks for readonly; escalates to `force-ssl` only when captions are actually requested (Decision 4) |
| `listMyVideos({ pageToken?, max? })` | `Promise<{ videos: [{ id, title, publishedAt, durationMs, thumb }], nextPageToken }>` | your uploads only (Decision 1) |
| `listCaptions({ videoId })` | `Promise<{ tracks: [{ id, language, trackKind, name }] }>` | `trackKind:'ASR'` marks auto-generated — **the download of which is the Phase-0 question** |
| `importYouTube({ videoId, trackId?, mask?, frameSource? })` | `Promise<{ captures, cues, strategy, masked, warnings }>` | the whole route B. `frameSource` is a File (route A) or `'tab'` (route C); omit it for captions-only, which produces captures with words and **no images** |
| `importTab({ mask? })` | `Promise<{ sessionId }>` | route C. Requires a gesture (tab picker). Runs in real time and says so |
| `setMask({ x, y, w, h })` / `suggestMask()` | `{ mask, basis }` | fractions of the frame. `suggestMask` proposes from per-pixel variance and returns `basis` naming the rule |
| `getCues()` | `{ cues: [{ tMs, endMs, text }], source }` | the caption cues verbatim — the source ships with the derived |

### `importYouTube` — the shape of the result

```js
{ captures: 41,
  cues: 812,                       // caption cues consumed
  strategy: 'video-led',           // or 'audio-led' when the mask failed
  masked: { x:0.05, y:0.08, w:0.62, h:0.70, basis:'suggested from frame variance' },
  words: 'captions',               // 'captions' | 'transcribed'
  warnings: [{ code, message }] }
```

`words` is not decoration. A consumer must be able to tell **auto-captions** from
**model transcription** from **captions the speaker edited by hand**, because they
are three different claims about accuracy — the same reason `moments[].textSource`
exists in the narrated-review export. Carry it onto every capture.

### Error codes (ingest)

`not-signed-in` · `not-your-video` (the API returns nothing for a video you do not
own — say that, do not say "no captions") · `no-captions` · `asr-download-refused`
(**distinct from `no-captions`** — a track exists and the API would not hand it
over; the user can act on that, and it is the Phase-0 unknown made visible at
runtime) · `mask-unusable` (intercut footage, Decision 3) · `tab-audio-unavailable`

## Part B — `talk-miner` (the corpus)

| Action | Returns | Note |
|---|---|---|
| `addTalk({ sessionId, videoId?, title?, date? })` | `Promise<{ talkId }>` | takes a finished narrated-review session into the corpus |
| `listTalks()` | `{ talks: [{ talkId, title, date, captures, words, hasImages }] }` | |
| `getTalk({ talkId })` | `Promise<{ session }>` | the unchanged narrated-review session |
| `removeTalk({ talkId })` | `Promise<{ removed }>` | |
| `groupSlides({ threshold? })` | `Promise<{ groups: [{ id, signature, uses: [{ talkId, captureId, tMs }] }] }>` | signature dedupe across talks. Threshold from `otsuSplit()` over observed distances unless passed |
| `proposeConcepts({ model?, maxSteps? })` | `Promise<{ concepts, costUsd, steps }>` | model-proposed, **every concept citing its captures** (Decision 8) |
| `getConcepts()` | `{ concepts: [...] }` | |
| `setConcept({ id, label?, best?, merge? })` | `{ concept }` | human curation: rename, pick the best articulation, merge two |
| `getCorpus()` | the whole machine-readable product | see below |
| `estimateCorpus({ talkIds? })` | `{ captures, transcribeUsd, cleanUsd, totalUsd, basis }` | **before** spending. Reuses the measured `COST_BASIS` |
| `buildConceptDoc({ conceptId })` | `Promise<{ markdown, images }>` | one idea, its slides, its best telling, every mention |
| `exportCorpus({ format })` | `Promise<{ name, bytes }>` | `json` \| `zip` \| `vault` |

### The concept

```js
{ id: 'c07',
  label: 'risk chains',
  summary: '…',                                  // model-written, one paragraph
  mentions: [{ talkId, captureId, tMs, quote }], // MUST be non-empty
  best: { talkId, captureId },
  slides: ['sg03'],                              // slide-group ids
  firstSeen: '2024-03-11', lastSeen: '2026-08-05',
  provenance: { model, generationId, at } }      // which call proposed it
```

**`mentions` must be non-empty or the concept is not stored.** That is the rule
Decision 8 turns into a shape: a concept with no citations is a claim with no
evidence, and this project has spent three releases making that impossible to
express by accident.

`provenance` carries the generation id so the concept lands in the same billing
ledger as everything else — `narrated-review` already records every generation at
the transport (`api/nr-billing.js`), and the corpus layer must not become the one
place spend escapes the receipt.

### `getCorpus()` — the machine-readable product

```js
{ schema: { name: 'talk-miner/corpus', version: 1 },
  talks: [{ talkId, videoId, title, date, captures, words, hasImages }],
  slideGroups: [{ id, uses: [{ talkId, captureId }], firstSeen, lastSeen }],
  concepts: [ … ],
  totals: { talks, captures, concepts, spendUsd },
  gaps_in_analysis: [{ code, message }] }
```

`gaps_in_analysis` is carried over from `media-probe` and is not optional. A corpus
where three talks were captions-only and therefore have **no images** looks, from
the outside, exactly like a corpus where those talks had no slides. Those are
different claims. Codes: `talk-no-images`, `talk-no-captions`,
`concepts-not-proposed`, `slides-not-grouped`.

## Events

| Event | Detail |
|---|---|
| `tm:talk:added` / `tm:talk:removed` | `{ talkId }` |
| `tm:slides:grouped` | `{ groups, threshold, basis }` |
| `tm:concepts:proposed` | `{ concepts, costUsd, steps }` |
| `tm:concept:updated` | `{ id, field }` |
| `tm:warning` | `{ code, message }` |
| `tm:export:complete` | `{ name, bytes, format }` |

Ingest events reuse the `nr:*` namespace, with `nr:youtube:*` for the new lane —
`nr:youtube:captions` (`{ tracks, chosen }`), `nr:youtube:progress`,
`nr:youtube:complete`.

## The canonical headless run

```js
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;

await t.connectYouTube({});
const { videos } = await t.listMyVideos({ max: 50 });

for (const v of videos.slice(0, 3)) {
  const { tracks } = await t.listCaptions({ videoId: v.id });
  const asr = tracks.find(x => x.trackKind === 'ASR');
  const r = await t.importYouTube({ videoId: v.id, trackId: asr?.id, frameSource: file });
  if (r.warnings.length) console.warn(v.title, r.warnings);
  await t.cleanAll();                       // fixes ASR vs the text on the slide
  await window.__corpus.addTalk({ sessionId: (await t.getStatus()).sessionId, videoId: v.id });
}

await window.__corpus.groupSlides({});      // free — no model call
console.log(await window.__corpus.estimateCorpus({}));   // BEFORE proposing
await window.__corpus.proposeConcepts({});
```

Note the order: **`groupSlides` before `proposeConcepts`**, and `estimateCorpus`
between them. Slide dedupe is free and tells the model which slides recur, which is
the single most useful prior it can have when looking for ideas that repeat.
