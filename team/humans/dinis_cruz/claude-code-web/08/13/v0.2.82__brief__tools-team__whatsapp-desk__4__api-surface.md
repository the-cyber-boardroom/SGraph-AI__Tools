# Brief — WhatsApp Desk · 4/5 API Surface

SgToolApi tool name `whatsapp-desk`, `window.__tool` live after `tool:ready`. Every user-visible action registered (the publisher's standard). Sending actions are deliberately granular — no one-shot auto-send exists (Decision 5).

## Methods (~24)

**Account (5)** — `connect({ token?, phoneNumberId?, wabaId? })` (persists, validates with a `GET` on the number), `disconnect()`, `setRelay({ url, token })`, `getStatus()`, `health()`. Token params masked via `sanitiseParams` (`'••••'`), publisher pattern.

**Inbound (5)** — `syncInbound()` (one relay pull; the pipeline also polls on its own while visible), `listConversations()` → rows incl. `windowExpiresAt` + unread, `openConversation({ id })` (focuses/creates the tab), `getMessages({ conversationId, limit? })`, `markRead({ messageId })`.

**Send (4)** — `sendText({ conversationId | to, body })` (typed `window-expired` client-side first), `sendTemplate({ to, name, lang, components? })`, `sendMedia({ to, file | mediaId, caption? })`, `listTemplates()` (approved only).

**Voice + AI (3)** — `transcribeVoiceNote({ messageId, model? })` → `{ text, costUsd }` (existing engine; result cached on the message), `draftReply({ conversationId, guidance?, model? })` → fills the composer + returns `{ draft }` — **never sends**, `getCostSummary()` (transcription + drafts, openrouter-cost rollup).

**Media + export (3)** — `downloadMedia({ messageId })` (browser-native save), `exportConversation({ conversationId, format: 'zip' })`, `sendConversationViaSgSend({ conversationId })`.

## Window events (`wa:*`, frozen in core sg-whatsapp-events.js)

`wa:connected` / `wa:disconnected` · `wa:sync { newMessages }` · `wa:message:in { conversationId, type }` · `wa:message:out { conversationId, messageId }` · `wa:receipt { messageId, status: sent|delivered|read }` · `wa:window:changed { conversationId, windowExpiresAt, open }` · `wa:transcript:complete { messageId, costUsd }` · `wa:draft:ready { conversationId }` · `wa:error { step, code, message }`. Plus `tool:ready`.

## Storage keys

`sg-whatsapp-token` · `sg-whatsapp-phone-id` · `sg-whatsapp-waba-id` · `sg-whatsapp-relay-url` · `sg-whatsapp-relay-token` · `sg-openrouter-mgmt-key` (existing). Conversation history: in-memory + relay's 72 h TTL in v0.1 (refresh loses older history — stated in SKILL-human; vault-backed archive is the v0.2 answer).

## Error codes

`auth-invalid`, `relay-unreachable`, `relay-auth`, `window-expired`, `template-unapproved`, `recipient-invalid`, `rate-limited`, `media-too-large`, plus the existing LLM family (`key-missing/key-invalid/…`) surfacing through transcribe/draft. Shape: `Error & { code, status? }` + `wa:error` mirror — the house convention.

## What an agent run looks like

```js
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;
await t.connect({});                          // creds already in localStorage
const { newMessages } = await t.syncInbound();

for (const conv of await t.listConversations()) {
  if (!conv.unread) continue;
  const msgs = await t.getMessages({ conversationId: conv.id });
  const last = msgs.at(-1);
  if (last.type === 'audio') {
    const { text } = await t.transcribeVoiceNote({ messageId: last.id });
    console.log('voice note said:', text);
  }
  const { draft } = await t.draftReply({ conversationId: conv.id,
      guidance: 'friendly, short, confirm and propose a time' });
  // Human-in-the-loop: the draft sits in the composer. An autonomous agent
  // may call sendText explicitly — that call, not the draft, is the consent.
  await t.sendText({ conversationId: conv.id, body: draft });
}
```
