# Brief — Video Publisher · 4/5 API Surface

SgToolApi tool name `video-publisher`, published on `window.__tool` after `tool:ready`. Every user-visible action has an API action — the recorder's UI-only YouTube button is the anti-pattern this corrects.

---

## Methods (~20)

**Source (4)**
- `importFile({file})` — load a video File/Blob, create the PublishJob.
- `getJob()` — full job state: step statuses, route used, costs, metadata, result.
- `reset()` — discard job.
- `setAutoRun({enabled})` — auto-advance through audio/transcribe/metadata (default true).

**Audio (2)**
- `extractAudio()` — run the Decision-2 route tree; returns `{route: 'native'|'remux'|'decode', bytes, mime}`.
- `getAudio()` — the audio blob descriptor (for debugging/export).

**Transcribe (4)**
- `transcribe({model?})` — default `google/gemini-3.5-flash`; returns `{text, model, costUsd, generationId}`.
- `getTranscript()` — current transcript text.
- `listModels()` — curated list (re-exported from audio-models).
- `setApiKey({apiKey, model?})` — persist + connect OpenRouter key.

**Metadata (4)**
- `generateMetadata({guidance?})` — strict-JSON `{title, description, tags[]}` from the transcript; `guidance` is the "more emojis / shorter" free-text steer.
- `setMetadata({title?, description?, tags?, privacy?})` — manual edits; `privacy` ∈ `public|unlisted|private` (default `unlisted`, matching the upload core).
- `getMetadata()`
- `getCostSummary()` — transcription + metadata generations, rolled up (openrouter-cost pattern).

**Publish (5)**
- `setClientId({clientId})` / `connectYouTube()` / `disconnectYouTube()` — GIS flow, youtube-editor pipeline pattern (cached token → silent re-grant → popup; params masked in console).
- `upload()` — resumable single-PUT with progress events; returns `{id, url}`. **Never called by autoRun.**
- `getStatus()` / `health()` — standard.

**One-shot**
- `publish({file?, model?, guidance?, privacy?, confirm: true})` — runs the whole chain and uploads. `confirm: true` is required (explicit consent to the outward-facing step); omitting it stops at `ready-to-publish`.

## Window events (`vp:*`, frozen in `publisher-events.js`)

`vp:job:loaded`, `vp:audio:start|complete {route}`, `vp:transcribe:start|complete {costUsd}`, `vp:metadata:start|complete`, `vp:upload:start|progress {percent}|complete {id,url}`, `vp:step:error {step, code}`, `vp:handoff-received {sourceTool, filename, byteSize, hasAudioBlob}`. Plus the inherited `tool:ready`.

## Storage keys (all pre-existing — Decision 5)

| Key | Owner pattern |
|---|---|
| `sg-openrouter-mgmt-key` | audio-transcribe |
| `sg-youtube-client-id` | youtube-editor (shared default client ID fallback) |
| `sg-auth-token-video-publisher` | sg-auth-tokens, provider `video-publisher` |
| `sgraph-send-token` | video-recorder / send-drop (optional share) |

## Error shape

`{code, step, message}` — codes reuse the existing typed families: `key-invalid|key-exhausted|budget-exceeded|rate-limited` (llm-errors), `too-large` (25 MB audio cap), `no-audio-stream` (all three routes failed), `auth-required|upload-failed` (YouTube), `handoff-empty`. Every step failure is retryable individually via its step method.

## What an agent run looks like end-to-end

```js
// tab opened directly (no handoff) — Playwright or console
await new Promise(r => addEventListener('tool:ready', r, { once: true }));
const t = window.__tool;

t.setApiKey({ apiKey: OPENROUTER_KEY });
await t.importFile({ file: myMp4 });          // autoRun kicks in:
//   vp:audio:complete {route:'remux'} → vp:transcribe:complete {costUsd:0.0687}
//   → vp:metadata:complete → job at 'ready-to-publish'

const { title } = t.getMetadata();
t.setMetadata({ privacy: 'public' });

await t.connectYouTube();                      // popup unless token cached
const { url } = await t.upload();              // vp:upload:progress … complete
console.log('published:', url);
```

Recorder-initiated run: the human clicks **Publish** in video-recorder; pickup fires `vp:handoff-received {hasAudioBlob:true}`, route 1 is free, and the human's remaining work is: review metadata → Upload → copy URL. Three interactions.
