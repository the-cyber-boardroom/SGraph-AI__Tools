## Hand-off — `handoff/sg-youtube-handoff.js`

The cross-tool bridge that lets any sibling tool send a video blob to the editor.

**Protocol:** same-origin `window.opener` stash. Producer tool sets `window.__sgYtHandoff = { blob, suggestedTitle, ... }` then opens the editor URL in a new tab. The editor's `ui-shell.js` calls `pickupHandoff()` at boot, which reads `window.opener.__sgYtHandoff`, deletes it, and dispatches a `sg-yt-handoff-pickup` window event. The Upload tab listens for that, creates a `File` from the blob, and pre-fills the form.

**Helper exports:**
- `sendToYouTubeEditor({ blob, suggestedTitle?, suggestedDescription?, filename?, sourceTool? })` — producer side
- `pickupHandoff()` — receiver side, returns the payload or null

The protocol is documented in `SKILL-api.md` so any future tool (transcoder, slideshow builder, …) can plug in without touching the editor.

## Recorder modification — `video-recorder/ui/ui-recording-tab.js` (v0.1.48)

A single new "Send to YouTube" button in the recorder's per-recording panel, alongside the existing SG/Send share section. On click:

```js
const { sendToYouTubeEditor } = await import(
    '/tools/v0/v0.1/v0.1.53/en-gb/youtube-editor/handoff/sg-youtube-handoff.js'
);
sendToYouTubeEditor({
    blob:           primaryBlob,
    suggestedTitle: name || `Recording ${new Date().toLocaleDateString('en-GB')}`,
    filename:       `${(name || 'recording').replace(/[^\w-]+/g, '_')}.webm`,
    sourceTool:     'video-recorder',
});
```

Lazy-imported on click — no eager load cost for users who don't use the hand-off. Opens a new tab; the editor pre-fills file + title automatically.

The recorder's v0.1.53 entry is just a stub (the actual code lives at v0.1.48), so the modification was made to v0.1.48 directly.

## Two-scope OAuth model

The editor's pipeline requests **both** scopes together in a single GIS call:

```
youtube + yt-analytics.readonly  ←  COMBINED_SCOPE constant
```

The user can grant a subset (Google's consent screen offers per-scope toggles). After grant, we inspect `r.scope` to find what was actually granted. `state.hasAnalytics` is `true` only if `yt-analytics.readonly` is in the returned scope string. Analytics features hide gracefully with an inline notice when the scope is missing.

The token cache provider key is `youtube-editor` (separate from `youtube-upload`), so both tools coexist with their own grants.
