## Core module — `sg-linkedin-api.js`

Pure JS, no DOM. Same shape as `core/youtube-api/sg-youtube-api.js`. Constructor takes the access token + (optionally) the proxy base URL.

```js
import { LinkedInApi, LINKEDIN_VERSION } from '/core/linkedin-api/v0/v0.1/v0.1.0/sg-linkedin-api.js';

const api = new LinkedInApi(accessToken, {
    proxyBaseUrl: 'https://proxy.tools.sgraph.ai/linkedin',  // null/undefined = direct
});

const me   = await api.getMe();                              // viewer's profile
const orgs = await api.getMyAdminOrganizations();            // org URNs the user can post as
const post = await api.createTextPost(orgUrn, { commentary: 'Hello' });
```

The proxy URL prefix is **optional**. When set, the class transparently rewrites the URL: `https://api.linkedin.com/...` → `${proxyBaseUrl}/...`. The proxy returns the LinkedIn response verbatim. Mode toggleable in tests.

LinkedIn's mandatory headers (`LinkedIn-Version`, `X-Restli-Protocol-Version: 2.0.0`) are added centrally in a single `_request()` helper. The version constant is exported so the tool's manifest can pin to a known-good version.

## Components

### `<sg-linkedin-post-editor>`
Compose a new post. Attributes: `default-visibility`. Slots for the org URN and access token (set via `setToken` / `setOrg` methods). Modes: `text`, `article`. Events: `post-published`, `post-error`. Mirrors the editing form pattern from `<sg-youtube-video-editor>` but for LinkedIn's post payload.

### `<sg-linkedin-post-list>`
Paginated list of recent posts for the current org. Each row: timestamp, commentary preview, type badge (TEXT / ARTICLE / IMAGE), engagement counts (if available). Click → `post-selected` event. Methods: `setToken`, `setOrg`, `refresh`, `loadMore`. Mirrors `<sg-youtube-videos>` pagination + `defer-and-replay` race protection pattern.

### `<sg-linkedin-org-picker>`
Lists organisations the user is admin of, shows logo + name, lets user select one. Emits `org-selected` with the URN. The "which page am I posting as?" picker in the auth panel.

## Tool layout (sg-layout)

```
┌──────────────┬──────────────────────────────────────────────────┐
│ 🔑 Account   │  ✏ Compose │ 📋 Recent Posts │ 📄 ... (per-post) │
│              │                                                   │
│ user info    │  right tab stack — per-post tabs accumulate       │
│ + sign out   │  when you click a row in Recent Posts             │
│              │                                                   │
│ ─── Org ───  │                                                   │
│ <picker>     │                                                   │
│ banner +     │                                                   │
│  name +      │                                                   │
│  followers   │                                                   │
└──────────────┴──────────────────────────────────────────────────┘
                                                       [▸ JS API]
```

**Auth panel changes vs YouTube:** the user (the human) is one identity, the **org** they're posting as is a separate identity. The org picker sits below the user card in the left panel and persists the choice in `localStorage['sg-linkedin-current-org']`. All tabs on the right reflect the currently-selected org.

**Compose tab** — text vs. article toggle at the top. Text mode: just commentary + visibility. Article mode: commentary + URL + title + description + thumbnail picker (uploads via the asset upload step → URN → reference in payload).

**Recent Posts tab** — same shape as YouTube's My Videos: header with refresh, filter input, list of post rows. Click → opens a per-post tab.

**Per-post tab** — read-only for v0.1 (LinkedIn's update API is `PARTIAL_UPDATE` semantics, deferred). Shows the full post, link to view it on LinkedIn, basic engagement counts.

## Hand-off from YouTube

A new helper `tools/.../linkedin-publisher/handoff/sg-linkedin-handoff.js` exports:

```js
sendToLinkedInPublisher({
    youtubeUrl:           'https://www.youtube.com/watch?v=...',
    suggestedCommentary:  'Just published a new demo of …',
    suggestedTitle:       'Recording title from YouTube',
    sourceTool:           'youtube-editor',
});
```

The youtube-editor's editor tab gets a new "▶ Share on LinkedIn" button (next to the Studio link) that calls this. The publisher's compose tab pre-fills as an article-link post with the YouTube URL.

This closes the workflow loop: **record → upload → publish on LinkedIn** without leaving tools.sgraph.ai.
