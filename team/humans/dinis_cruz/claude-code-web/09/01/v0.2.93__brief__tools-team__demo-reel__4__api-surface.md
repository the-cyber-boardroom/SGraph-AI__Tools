# demo-reel — 4 · API surface

*All PROPOSED. `window.__tool` after `tool:ready`; every action returns a Promise.
The JS API is the authoring surface — the UI is one consumer of it, and an agent
is the other.*

## The agent path, end to end

```js
const t = window.__tool;

await t.importSession({ file: sessionZip });        // or newReel(), or setReel()
await t.mergeScenes({ ids: ['s02', 's03'] });       // three captures → one scene
await t.setScene({ id: 's02', caption: 'No password reset. Ever.' });
await t.addAnnotation({ sceneId: 's02', shotIndex: 0,
                        type: 'box', at: [0.30, 0.42, 0.36, 0.08], label: 'the vault key' });
await t.setFocus({ sceneId: 's02', shotIndex: 0, focus: [0.24, 0.08, 0.52, 0.70] });

const check = await t.validate({});                  // BEFORE spending time rendering
if (!check.ok) throw new Error(JSON.stringify(check.problems));

await t.generateAudio({});                           // Kokoro, cached by content hash
await t.render({ format: 'landscape' });
await t.render({ format: 'shorts' });
await t.downloadBundle({});
```

Nothing above needs a click, a key, or a visible tab beyond what MediaRecorder
requires. That is the point.

## Document

| Action | Returns | Notes |
|---|---|---|
| `newReel({title, theme, voice})` | the reel | Empty, valid. |
| `getReel()` | the reel | The whole document. |
| `setReel({reel})` | `{ok, problems}` | Replaces wholesale; **validates first and refuses an invalid one** rather than half-applying it. |
| `importSession({file \| sessionId})` | `{scenes, skipped}` | narrated-review zip, handover zip, or a `sg-vfs` session id. `skipped` lists captures left out and **why** — see below. |
| `importImages({files})` | `{scenes}` | Loose screenshots → one single-shot scene each, no narration. |
| `validate()` | `{ok, problems[]}` | `{scene, shot, code, message}`. Runs without rendering anything. |

**`importSession` skips rather than guesses.** A capture whose `textSource` is
`raw` — never corrected against its screenshot — is reported in `skipped` with
`code: 'uncorrected-transcript'`, not silently promoted to narration. Pass
`{force: true}` to take it anyway. Publishing a possibly-misheard sentence is a
different class of mistake from having one fewer scene.

## Scenes

| Action | Returns |
|---|---|
| `addScene({at?, narration?, caption?, shots?})` | the scene |
| `setScene({id, narration?, caption?, weight?})` | the scene |
| `moveScene({id, toIndex})` | `{id, index}` |
| `removeScene({id})` | `{removed}` |
| `mergeScenes({ids})` | the merged scene — shots concatenated, narration joined, first caption kept |
| `splitScene({id, atShotIndex})` | `{scenes: [a, b]}` |
| `addShot({sceneId, image, at?})` / `removeShot({sceneId, index})` | the scene |
| `setFocus({sceneId, shotIndex, focus})` | `{ok, warnings}` — warns when the rect cannot survive a 9:16 crop |

## Annotations

| Action | Returns |
|---|---|
| `addAnnotation({sceneId, shotIndex, …})` | the annotation, with an id |
| `updateAnnotation({id, …})` / `removeAnnotation({id})` | the shot |
| `listAnnotations({sceneId?})` | all of them, flat |

Primitives: `box` · `circle` · `arrow` · `highlight` · `blur` · `tagline` ·
`label` · `pointer`.

```jsonc
{ "id": "a01", "type": "box", "at": [x, y, w, h],   "label": "…", "in": 0.4, "style": "accent" }
{ "id": "a02", "type": "arrow", "from": [x, y], "to": [x, y], "curve": 0.2 }
{ "id": "a03", "type": "blur", "at": [x, y, w, h], "radius": 12, "reason": "customer name" }
{ "id": "a04", "type": "tagline", "at": "bottom", "text": "…" }
```

All coordinates normalised **to the source image**, so one set of numbers serves
every output size.

`blur` carries a `reason`. It costs nothing and it means a reviewer six months
later can tell a deliberate redaction from a decorative smudge — the same
reasoning that made `redacted` a counted field in the page recorder.

## Audio

| Action | Returns | Notes |
|---|---|---|
| `listVoices()` | `{voices}` | From `core/sg-tts`. |
| `generateAudio({sceneIds?})` | `{generated, cached, totalMs}` | Kokoro. **Cached on `hash(narration+voice+speed)`** — editing one sentence re-speaks one scene. |
| `getTiming()` | `{scenes:[{id, audioMs, shots:[{ms}]}]}` | The computed timeline, before rendering. Cheap, and the thing to check when a reel feels rushed. |
| `setVoice({id, speed})` | `{voice}` | Invalidates the cache. |

## Render

| Action | Returns | Notes |
|---|---|---|
| `previewFrame({t, format})` | `{dataUrl}` | Deterministic — the same `t` always gives the same frame. The backbone of the tests. |
| `render({format, fps?, bitrateKbps?})` | `{blob, name, durationMs, intendedMs, drift}` | **`drift` is reported, always.** |
| `renderAll()` | `{landscape, shorts}` | |
| `cancelRender()` | `{cancelled}` | |
| `exportFrames({format, everyMs})` | `{frames}` | PNG stills — for review, thumbnails, and diffing a render against a known-good one without watching a video. |
| `downloadBundle()` | `{name, bytes}` | `reel.json` + `images/` + `audio/` + `out/`. |

**`render` returns `drift` — the gap between intended and actual duration — on
every call, not only when something goes wrong.** A video whose audio has slipped
half a second from its captions is the failure mode here, and it is invisible
unless the number is in front of you. If Phase 0 shows drift is real, this field
is how anyone notices.

## Events

`dr:reel:changed` · `dr:scene:added` · `dr:scene:updated` · `dr:scenes:reordered` ·
`dr:annotation:changed` · `dr:audio:progress` · `dr:audio:complete` ·
`dr:render:started` · `dr:render:progress` · `dr:render:complete` ·
`dr:validate:problems` · `dr:warning` · `dr:reset`

`dr:warning` codes: `focus-too-wide` (cannot make 9:16 honestly) ·
`shot-too-short` (below the 800 ms floor) · `caption-derived` (guessed, not
written) · `caption-overflow` (will not fit legibly) · `uncorrected-transcript` ·
`drift-high`.

## Error codes

`bad-params` · `invalid-reel` (with positional problems) · `no-scenes` ·
`missing-image` · `tts-unavailable` · `render-unsupported` (no MediaRecorder
codec) · `cancelled`

## What a validation problem looks like

```json
{ "ok": false, "problems": [
  { "scene": "s03", "shot": 1, "code": "focus-too-wide",
    "message": "focus rect is 0.82 wide; a 9:16 crop of this 16:9 source can show at most 0.56. Narrow the focus, split the shot, or drop 'shorts' from formats." },
  { "scene": "s07", "code": "shot-too-short",
    "message": "5 shots over 3.9s of narration is 780ms each, below the 800ms floor. Merge two shots or lengthen the narration." }
]}
```

Positional, and each says **what to do about it**. An agent authoring JSON cannot
see the preview; the error message is the entire feedback channel, so it has to
carry the fix, not just the complaint.
