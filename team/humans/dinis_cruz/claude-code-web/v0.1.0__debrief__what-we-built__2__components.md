# Debrief 2b — What We Built · Components

**Date:** 25 April 2026 · **Branch:** `claude/new-tool-component-EzK43`

Four new Web Components. All extend `SgComponent` (`/components/base/v1/v1.0/v1.0.0/sg-component.js`) — Shadow DOM, async template loading, `whenReady()` guard. All composed events bubble out of the shadow root.

---

## `<sg-youtube-upload>` — embeddable upload widget

**Path:** `components/video/upload/sg-youtube-upload/v0/v0.1/v0.1.0/`
**Files:** `manifest.json`, `sg-youtube-upload.{js,html,css}`, `youtube-token-cache.js`

Self-contained: shows the OAuth client-ID input, Connect/Sign-out, file picker (click + drag-drop), title/description/tags/privacy form, progress bar, result link. Used standalone on the v0.1.0 test page; superseded by the editor's bespoke upload tab in the bigger tool.

**Attributes:** `client-id`, `default-privacy`, `default-title`, `auto-connect`
**Methods:** `setFile(file)`, `connect({silent})`, `upload(override)`, `signOut()`, `isConnected()`
**Events:** `youtube-{connected,disconnected,file-set,upload-start,upload-progress,upload-complete,upload-error}`
**Token cache:** `youtube-token-cache.js` provider key `youtube-upload`, 60 s expiry skew

## `<sg-youtube-videos>` — paginated uploads grid

**Path:** `components/video/manage/sg-youtube-videos/v0/v0.1/v0.1.0/`

Grid of the signed-in user's uploads. After each `listMyUploads` page, follow-up `getVideos()` enriches rows with privacy badge, view count (`12.3K`/`1.2M` formatted), and ISO-8601 duration → `m:ss`/`h:mm:ss`.

Built-in toolbar:
- **Filter** — text input matches title + description on already-loaded items (no API calls)
- **Sort** — Newest / Oldest / Most viewed / Longest / Shortest / Title A→Z

**Attributes:** `page-size` (≤ 50), `auto-load`
**Methods:** `setToken(t)`, `refresh()` (defers until `onReady` if called pre-bind), `loadMore()`, `getItems()`
**Events:** `videos-loaded`, `videos-error`, `video-selected`

## `<sg-youtube-video-editor>` — per-video editor

**Path:** `components/video/manage/sg-youtube-video-editor/v0/v0.1/v0.1.0/`

The most complex component — full edit form for one video plus inline preview, playlist picker, and analytics block.

**Header**: thumbnail · title · video id · 3 links (`Open on YouTube ↗`, `Open in Studio ↗`, `⬇ Download (Studio)` with explanatory tooltip) · Preview toggle button · privacy badge

**Form**: title, description, tags, privacy (with auto-`categoryId` fallback)

**Preview** (`▶ Preview` toggle): lazy-loads `youtube.com/embed/{id}` iframe; only fetched on first open

**Replace thumbnail**: image picker → `setThumbnail()` (≤ 2 MB JPG/PNG)

**Playlist picker**:
- Lists user's playlists with checkboxes (max ~50)
- Ticked = video is in that playlist
- Tick → `addToPlaylist`; un-tick → `removeFromPlaylist`
- Optimistic UI: checkbox flips immediately, rolls back on failure
- Membership detected via fanout `findVideoPlaylists()` (1 unit per playlist queried)

**📈 Analytics block** (only renders if analytics scope granted):
- Window selector: 7 / 28 / 90 / 365 days
- 6 metric tiles: Views · Watch hrs · Avg view (m:ss) · Avg % · Subs gained · Likes
- Audience retention chart — pure SVG line + gradient area, scaled to 100% baseline. Falls back to "not enough views yet" gracefully when YouTube returns empty for low-view videos.

**Save**: button briefly flashes brighter teal + "✓ Saved" (1.4 s CSS keyframe `yte-saved-flash`), restartable on subsequent saves.

**Danger zone** (`allow-delete` attribute, **not** set by the editor tool): typed-title-confirm delete. Component still has `deleteVideo()` for SDK callers.

**Attributes:** `allow-delete` (boolean)
**Events:** `video-{loaded,saved,deleted,thumbnail-set,playlists-changed,error}`

## `<sg-youtube-playlists>` — collapsible playlists list

**Path:** `components/video/manage/sg-youtube-playlists/v0/v0.1/v0.1.0/`

Header rows showing playlist thumbnail + title + item count. Click a row to expand and lazy-load its videos (cached per playlist after first expand). Inner item click → `playlist-item-selected` event, which the tool forwards to the same VIDEO_SELECTED flow that opens an editor tab.

**Visual hierarchy** (after iteration): expanded row has teal border + soft glow, header gets tinted teal, items inset with a teal accent bar on the left, each item list capped at `max-height: 360px` with its own scroll so multiple expansions co-exist.

**Methods:** `setToken(t)`, `refresh()`, `getItems()`
**Events:** `playlists-loaded`, `playlists-error`, `playlist-expanded`, `playlist-item-selected`
