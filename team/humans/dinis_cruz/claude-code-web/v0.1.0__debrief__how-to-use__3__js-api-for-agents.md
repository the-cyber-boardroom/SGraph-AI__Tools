# Debrief 3c — How to Use · JS API for Agents

**Date:** 25 April 2026

This is the operating manual for **Claude Agents driving the YouTube editor via Chromium**, plus Playwright-style automation tests. Same surface, same patterns infographic-gen exposes today.

---

## Where the API lives

```
window.__tool['youtube-editor']        ← the tool's API (after tool:ready)
window.__tool['video-recorder']        ← the recorder's API (in its tab)
window.__tools                         ← map of every tool's API by instanceId
window.__tool                          ← current tool's API (when only one is loaded)
```

Wait for `tool:ready`:

```js
await page.waitForFunction(() => window.__tool?.['youtube-editor']);
```

## Skip the OAuth popup with a primed token

Before navigating to the tool, prime the token cache via `addInitScript`:

```js
await page.addInitScript(() => {
    localStorage.setItem('sg-auth-token-youtube-editor', JSON.stringify({
        provider:    'youtube-editor',
        accessToken: 'fake-token-for-test',
        expiresAt:   Date.now() + 3_600_000,
        scope:       'https://www.googleapis.com/auth/youtube https://www.googleapis.com/auth/yt-analytics.readonly',
        savedAt:     Date.now(),
    }));
});
```

`api.connect()` then resolves immediately from cache — no Google call.

`state.hasAnalytics` becomes `true` because the `scope` string contains `yt-analytics.readonly` (the pipeline checks `scope.includes(YOUTUBE_ANALYTICS_SCOPE)`). Drop that part of the string to test the "analytics not granted" UI path.

## Drive a flow end-to-end

```js
const tool = () => window.__tool['youtube-editor'];

// 1. Connect (cache hit, instant)
await page.evaluate(() => tool().connect());

// 2. Channel + 28-day analytics
const channel = await page.evaluate(() => tool().getMyChannel());
const summary = await page.evaluate(() => tool().getChannelAnalyticsSummary({ days: 28 }));

// 3. List uploads, pick one
const list = await page.evaluate(() => tool().listMyUploads());
const id   = list.items[0].id;

// 4. Load it, edit it, save it
const video = await page.evaluate(v => tool().loadVideo({ id: v }), id);
const saved = await page.evaluate(v => tool().updateVideo({
    id: v,
    patch: { snippet: { title: 'Edited via API' } },
}), id);

// 5. Per-video analytics + retention
const vSummary  = await page.evaluate(v => tool().getVideoAnalyticsSummary({ videoId: v, days: 28 }), id);
const retention = await page.evaluate(v => tool().getVideoRetention({ videoId: v }), id);

// 6. Add to a playlist
const playlists = await page.evaluate(() => tool().listMyPlaylists());
const plId      = playlists.items[0].id;
await page.evaluate(([v, p]) => tool().addToPlaylist({ playlistId: p, videoId: v }), [id, plId]);
```

## Upload from a Buffer (or remote URL)

```js
await page.evaluate(async () => {
    const blob = new Blob([new Uint8Array(1024)], { type: 'video/webm' });
    const file = new File([blob], 'test.webm', { type: 'video/webm' });
    return await window.__tool['youtube-editor'].uploadVideo({
        file,
        metadata: {
            title:         'Programmatically uploaded',
            description:   'From a Claude Agent',
            privacyStatus: 'unlisted',
        },
    });
});
```

To stub the upload itself (resumable: POST then PUT):

```js
await page.route('**/upload/youtube/v3/videos**', r => {
    if (r.request().method() === 'POST') {
        return r.fulfill({ status: 200,
            headers: { Location: 'https://upload.example/session/123' }, body: '' });
    }
    return r.continue();
});
await page.route('https://upload.example/session/**', r =>
    r.fulfill({ status: 200, body: JSON.stringify({ id: 'fake-vid' }) }));
```

## Listen for events

Every method emits one or more `tool:youtube:*` window events. Mirror them into Node:

```js
await page.exposeFunction('onYt', (name, detail) => console.log(name, detail));
await page.evaluate(() => {
    [
        'tool:ready',
        'tool:youtube:connected', 'tool:youtube:disconnected',
        'tool:youtube:channel-loaded',
        'tool:youtube:videos-loaded', 'tool:youtube:video-selected',
        'tool:youtube:video-loaded', 'tool:youtube:video-saved', 'tool:youtube:video-deleted',
        'tool:youtube:thumbnail-set',
        'tool:youtube:upload:start', 'tool:youtube:upload:progress', 'tool:youtube:upload:complete',
        'tool:youtube:playlists-loaded', 'tool:youtube:playlist-expanded', 'tool:youtube:playlists-changed',
        'tool:youtube:handoff-received',
        'tool:youtube:analytics-channel', 'tool:youtube:analytics-video', 'tool:youtube:analytics-retention',
        'tool:error',
    ].forEach(n => addEventListener(n, e => window.onYt(n, e.detail)));
});
```

## Hand-off from another tool (programmatic)

If your agent is in the recorder tab and wants to push to the editor:

```js
await page.evaluate(async () => {
    const blob = /* the recording — get from window.__tool['video-recorder'].getStatus() etc. */;
    const { sendToYouTubeEditor } = await import(
        '/tools/v0/v0.1/v0.1.53/en-gb/youtube-editor/handoff/sg-youtube-handoff.js'
    );
    sendToYouTubeEditor({
        blob,
        suggestedTitle: 'Demo from agent',
        sourceTool:     'video-recorder',
    });
});
```

`window.open` is called from within the agent's tab, so popup blockers won't fire (treated as a user gesture in Playwright). The opened editor reads `window.opener.__sgYtHandoff` and pre-fills the form.

## Health checks

```js
const tool = () => window.__tool['youtube-editor'];

const meta   = await page.evaluate(() => tool().meta.getManifest());
const events = await page.evaluate(() => tool().meta.getEvents());
const skills = await page.evaluate(() => tool().meta.getSkills());      // returns SKILL contents
const log    = await page.evaluate(() => tool().meta.getLog());         // last 500 invocations
const health = await page.evaluate(() => tool().health());              // ok / connected / quota / etc.
```

`tool().health()` is the smoke-test answer: `{ ok, connected, expiresInMs, videosLoaded, editingVideoId, uploadStatus, uploadProgress, clientIdSet }`.

## Storage keys (per-origin)

```
localStorage['sg-youtube-client-id']            ← OAuth client ID
localStorage['sg-auth-token-youtube-editor']    ← { accessToken, expiresAt, scope, savedAt }
localStorage['sg-auth-token-youtube-upload']    ← (only used by the focused youtube-upload tool)
localStorage['sg-auth-token-google']            ← (only used by sg-auth-google component, if present)
```

Clear them all to reset:

```js
['sg-youtube-client-id',
 'sg-auth-token-youtube-editor',
 'sg-auth-token-youtube-upload'].forEach(k => localStorage.removeItem(k));
```

## What this enables for agents

The killer use case: **a Claude Agent in a Chromium tab can do the entire publishing workflow without a human in the loop.**

- Open the recorder, record a screen demo programmatically (via `window.__tool['video-recorder']`).
- Stop, get the blob.
- Send it to the editor via the handoff helper.
- In the editor, set title from a prompt, set privacy to unlisted, upload.
- After upload completes, fetch analytics for the new video.
- Add it to a playlist.
- Pull retention data after a few days to gauge how it landed.

Every step is a single `await page.evaluate(...)` call. The same patterns infographic-gen already proves work in production.
