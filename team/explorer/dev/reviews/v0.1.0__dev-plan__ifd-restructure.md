# Dev Plan: IFD Restructure + MVP Infrastructure

**Version:** v0.1.0
**Date:** 5 Mar 2026
**Role:** Dev (Explorer team)
**Input:** SG/Send team debrief (`team/explorer/librarian/reviews/v0.1.0__debrief__sg-send-team-to-tools-team.md`)

---

## Objective

Restructure the Tools repo to match SG/Send conventions: IFD version paths, `sgraph_ai_tools__static/` base folder, CI pipeline, i18n support, and the `_common/en-gb/i18n` folder pattern.

---

## Tasks (in execution order)

### Phase 1: Folder Restructure

**1.1 Create `sgraph_ai_tools__static/` base folder with IFD nested version paths**

Move existing files from flat version folders to IFD nested paths:

```
core/crypto/v1.0.0/           → sgraph_ai_tools__static/core/crypto/v1/v1.0/v1.0.0/
core/ssh/v1.0.0/              → sgraph_ai_tools__static/core/ssh/v1/v1.0/v1.0.0/
components/header/v1.0.0/     → sgraph_ai_tools__static/components/header/v1/v1.0/v1.0.0/
components/footer/v1.0.0/     → sgraph_ai_tools__static/components/footer/v1/v1.0/v1.0.0/
```

**1.2 Create `manifest.json` for each module**

Each core module and component gets a manifest declaring its exports, version, and dependencies.

**1.3 Restructure tools into `_common/en-gb/i18n` pattern**

```
sgraph_ai_tools__static/tools/v0/v0.1/v0.1.0/
  _common/css/tools.css        ← shared CSS extracted from HTML pages
  en-gb/
    index.html                 ← landing page (with data-i18n attributes)
    ssh-keygen/index.html      ← SSH keygen tool (with data-i18n attributes)
  i18n/
    en-gb.json                 ← master translations
    en-us.json
    fr-fr.json
    de-de.json
    es-es.json
  index.html                   ← locale redirect (auto-detect browser language)
  404.html
  manifest.json
  robots.txt
  sitemap.xml
```

**1.4 Update all import paths**

HTML files use absolute paths from site root for core/components:
```html
<script type="module" src="/components/header/v1/v1.0/v1.0.0/sg-header.js"></script>
<script type="module" src="/core/ssh/v1/v1.0/v1.0.0/sg-ssh.js"></script>
```

And relative paths for `_common/`:
```html
<link rel="stylesheet" href="../_common/css/tools.css">
```

**1.5 Add `data-i18n` attributes to all translatable text**

Every user-facing string in HTML gets a `data-i18n="key"` attribute matching the i18n JSON keys.

**1.6 Delete old `core/`, `components/`, `tools/` folders**

After files are moved, remove the old flat-version structure.

### Phase 2: CI/CD Infrastructure

**2.1 Create `version` file** at repo root containing `v0.1.0`.

**2.2 Copy `scripts/deploy_static_site.py`** from SG/Send repo (unchanged — it's generic).

**2.3 Adapt `scripts/generate_tools_i18n_pages.py`** from Send's `generate_send_i18n_pages.py`:
- Change `UI_BASE` to point to `sgraph_ai_tools__static/tools`
- Start with 4 locales: en-us, fr-fr, de-de, es-es

**2.4 Adapt `scripts/inject_build_version.py`** for Tools repo paths.

**2.5 Create GitHub Actions workflows:**
- `deploy-tools__dev.yml` — triggered on push to `dev`, deploys to `websites/sgraph-tools/dev/`
- `deploy-tools__main.yml` — triggered on push to `main`, deploys to `websites/sgraph-tools/main/`

### Phase 3: Cleanup & Documentation

**3.1 Update `.gitignore`** — add CI-generated locale folders and build-info.js.

**3.2 Update reality document** — reflect new paths, new files, new infrastructure.

## What This Does NOT Include

- New crypto code (debrief says use static.sgraph.ai URLs)
- Video Splitter, LLM Client, or any new tools
- `latest/` folders (CI-only concept per debrief)
- Full 17-locale support (starting with 5: en-gb + 4 generated)

---

## Import Path Strategy

When deployed to S3, `sgraph_ai_tools__static/` becomes the site root. So:

| File Location (in repo) | URL (deployed) |
|---|---|
| `sgraph_ai_tools__static/core/crypto/v1/v1.0/v1.0.0/sg-crypto.js` | `https://tools.sgraph.ai/core/crypto/v1/v1.0/v1.0.0/sg-crypto.js` |
| `sgraph_ai_tools__static/components/header/v1/v1.0/v1.0.0/sg-header.js` | `https://tools.sgraph.ai/components/header/v1/v1.0/v1.0.0/sg-header.js` |
| `sgraph_ai_tools__static/tools/v0/v0.1/v0.1.0/en-gb/index.html` | `https://tools.sgraph.ai/tools/v0/v0.1/v0.1.0/en-gb/index.html` |

Via `latest/` (CI-created in S3): same paths under `https://tools.sgraph.ai/` since latest copies the whole release.

## Acceptance Criteria

1. All code lives under `sgraph_ai_tools__static/` with IFD nested version paths
2. No `latest/` folders in the repo
3. Every module has a `manifest.json`
4. Tools follow `_common/en-gb/i18n` pattern
5. HTML pages have `data-i18n` attributes on translatable text
6. CI workflows exist and reference correct paths
7. Deploy scripts are present and adapted for Tools
8. i18n JSON files exist for en-gb + 4 starter locales
9. Reality document is updated to reflect new state
10. Old flat-version folders are removed
