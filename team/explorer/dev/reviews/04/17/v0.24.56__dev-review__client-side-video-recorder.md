## 6. Risk Assessment

| Risk | Severity | Mitigation |
|------|----------|-----------|
| `getDisplayMedia` requires user gesture — cannot be triggered programmatically | **MED** | Button click → immediate `getDisplayMedia()` call; never inside async chain after delay |
| Safari screen capture support (limited) | **MED** | `isScreenSupported()` check; degrade gracefully with tooltip "Screen capture not available in this browser" |
| Large recordings (>1 GB) may OOM before encryption | **HIGH** | Progressive chunked MediaRecorder + streaming encryption. Do NOT buffer full recording in memory before encrypting |
| PiP canvas compositing degrades under load on low-end hardware | **LOW** | Default `scale: 0.2` keeps camera overlay small; disable PiP option if rAF drops below 15fps |
| `saveFolder` screenshots require FFmpeg or canvas seek — FFmpeg.wasm adds 40 MB | **MED** | Use canvas + video.currentTime seeking for screenshots (no FFmpeg needed for simple frame grabs) |
| Vault write API compatibility — vault components vary by version | **MED** | Pin to specific vault-write module version; do not use `@latest` |
| Folder save: no encryption specified in brief for folder output | **LOW** | Clarify with human: should folder video be encrypted? Brief implies only SG/Send and vault are encrypted |
