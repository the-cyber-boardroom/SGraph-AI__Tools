## What We're Building

A standalone browser tool at `tools.sgraph.ai/en-gb/image-tools/` that combines:

1. **Format conversion** — PNG ↔ JPG ↔ WebP ↔ AVIF
2. **Resize** — by pixels or percentage, with aspect ratio lock
3. **Crop** — visual drag-to-select region
4. **Redact** — draw black/blurred rectangles over sensitive areas
5. **Text/titles** — add text overlays with basic styling

Everything runs client-side via the Canvas API. No server, no upload, no dependencies beyond the browser.

## Architecture: Components Do the Heavy Lifting

The tool page (`index.html`) is a **thin orchestrator** that wires together reusable components and a core module. The actual image processing logic lives in `core/` and the interactive UI elements live in `components/`. This follows the project's three-tier pattern and means the same image processing capabilities can be reused by send.sgraph.ai's gallery editor, vault browser, or any future consumer.

## Operation Stack Model

The editor uses a non-destructive editing model. The original image is never modified. Operations are stacked and rendered in order via `renderOperations()`.

```javascript
const state = {
    original: null,      // Original Image element (never mutated)
    operations: [],      // Ordered list of operations
    outputFormat: 'image/png',
    outputQuality: 0.92, // For JPEG/WebP (0.0–1.0)
};

// Operation types:
// { type: 'crop',    x, y, width, height }
// { type: 'resize',  width, height }
// { type: 'redact',  regions: [{ x, y, w, h, mode: 'black'|'blur' }] }
// { type: 'text',    text, x, y, fontSize, fontFamily, color, align, bold, italic }
```

### Render Pipeline

```javascript
function renderPreview() {
    let canvas = document.createElement('canvas');
    let ctx = canvas.getContext('2d');

    // Start with original dimensions
    canvas.width  = state.original.naturalWidth;
    canvas.height = state.original.naturalHeight;
    ctx.drawImage(state.original, 0, 0);

    for (const op of state.operations) {
        switch (op.type) {
            case 'crop':
                canvas = applyCrop(canvas, op);
                ctx = canvas.getContext('2d');
                break;
            case 'resize':
                canvas = applyResize(canvas, op);
                ctx = canvas.getContext('2d');
                break;
            case 'redact':
                applyRedact(ctx, op);
                break;
            case 'text':
                applyText(ctx, op);
                break;
        }
    }

    return canvas;
}
```

This means any operation can be undone by removing it from the stack and re-rendering.

## Feature Specs

### 1. Format Conversion

Convert between formats using `canvas.toBlob()`:

```javascript
function exportImage(canvas, format, quality) {
    return new Promise((resolve) => {
        canvas.toBlob((blob) => resolve(blob), format, quality);
    });
}
```

| Format | MIME | Quality slider | Notes |
|---|---|---|---|
| PNG | `image/png` | No (lossless) | Default output |
| JPEG | `image/jpeg` | Yes (0.1–1.0, default 0.92) | No transparency — white background |
| WebP | `image/webp` | Yes (0.1–1.0, default 0.90) | Good compression, wide support |
| AVIF | `image/avif` | Yes (0.1–1.0, default 0.80) | Best compression, check browser support |

**AVIF support detection:**

```javascript
function supportsAvif() {
    const canvas = document.createElement('canvas');
    canvas.width = canvas.height = 1;
    return canvas.toDataURL('image/avif').startsWith('data:image/avif');
}
```

If AVIF isn't supported, grey out the option with "Not supported in this browser".

**JPEG transparency handling:** When converting to JPEG, composite onto a white background first:

```javascript
function flattenTransparency(sourceCanvas) {
    const c = document.createElement('canvas');
    c.width = sourceCanvas.width;
    c.height = sourceCanvas.height;
    const ctx = c.getContext('2d');
    ctx.fillStyle = '#ffffff';
    ctx.fillRect(0, 0, c.width, c.height);
    ctx.drawImage(sourceCanvas, 0, 0);
    return c;
}
```

**Output info:** Show estimated file size after conversion (render to blob, check `blob.size`). Display: "PNG 2.4 MB → WebP 380 KB (84% smaller)".

### 2. Resize

Two input modes, both with live preview:

**By pixels:**
```
Width:  [ 1920 ] px    Height: [ 1080 ] px    [🔒 Lock aspect ratio]
```

**By percentage:**
```
Scale:  [ 50 ] %       → 960 × 540 px
```

When aspect ratio is locked (default), changing one dimension auto-calculates the other.

```javascript
function applyResize(canvas, { width, height }) {
    const c = document.createElement('canvas');
    c.width = width;
    c.height = height;
    const ctx = c.getContext('2d');
    ctx.imageSmoothingEnabled = true;
    ctx.imageSmoothingQuality = 'high';
    ctx.drawImage(canvas, 0, 0, width, height);
    return c;
}
```

**Common presets** (quick buttons):

| Preset | Size | Use case |
|---|---|---|
| HD | 1920 × 1080 | Standard screen |
| Thumbnail | 200 × 200 | Gallery thumbnails |
| Social | 1200 × 630 | Open Graph / social cards |
| 50% | Half dimensions | Quick downscale |
| 25% | Quarter dimensions | Email-safe |

### 3. Crop

Interactive crop overlay on the preview canvas:

**Interaction:**
1. Click and drag on the preview to draw a crop rectangle
2. Drag corners/edges to adjust
3. Crop region shows actual pixel dimensions
4. Darkened area outside crop region (50% black overlay)
5. [Apply Crop] / [Cancel]

**Implementation — overlay canvas:**

```javascript
// A second canvas layered on top of the preview for crop interaction
const overlay = document.createElement('canvas');
overlay.style.position = 'absolute';
overlay.style.top = '0';
overlay.style.left = '0';
overlay.style.cursor = 'crosshair';

let cropRect = null; // { startX, startY, endX, endY }

overlay.addEventListener('pointerdown', (e) => {
    cropRect = { startX: e.offsetX, startY: e.offsetY, endX: e.offsetX, endY: e.offsetY };
});

overlay.addEventListener('pointermove', (e) => {
    if (!cropRect) return;
    cropRect.endX = e.offsetX;
    cropRect.endY = e.offsetY;
    drawCropOverlay();
});

overlay.addEventListener('pointerup', () => {
    // Show Apply/Cancel buttons
});
```

**Scale mapping:** The preview is displayed at a scaled size (fit to container). Crop coordinates must be mapped from display pixels to actual image pixels:

```javascript
function displayToImage(displayX, displayY, previewCanvas, imageCanvas) {
    const scaleX = imageCanvas.width / previewCanvas.clientWidth;
    const scaleY = imageCanvas.height / previewCanvas.clientHeight;
    return { x: Math.round(displayX * scaleX), y: Math.round(displayY * scaleY) };
}
```

**Aspect ratio presets** (optional quick buttons): Free, 1:1, 4:3, 16:9, 3:2.

```javascript
function applyCrop(canvas, { x, y, width, height }) {
    const c = document.createElement('canvas');
    c.width = width;
    c.height = height;
    const ctx = c.getContext('2d');
    ctx.drawImage(canvas, x, y, width, height, 0, 0, width, height);
    return c;
}
```

### 4. Redact

Draw rectangles over sensitive areas to permanently obscure them.

**Two modes:**
- **Black fill** — solid black rectangle (default, simpler, guaranteed secure)
- **Blur** — pixelated/blurred rectangle (looks better but must be irreversible)

**Interaction:**
1. Enter Redact mode (toolbar button)
2. Click+drag rectangles on the preview
3. Each rectangle appears as a numbered overlay with a [×] to remove
4. Multiple rectangles allowed
5. [Done Redacting] to commit

**Blur implementation (pixelation, not Gaussian — simpler and irreversibly destructive):**

```javascript
function applyRedact(ctx, { regions }) {
    for (const r of regions) {
        if (r.mode === 'black') {
            ctx.fillStyle = '#000000';
            ctx.fillRect(r.x, r.y, r.w, r.h);
        } else if (r.mode === 'blur') {
            // Pixelation: draw region small then scale back up
            const pixelSize = 10;
            const tempCanvas = document.createElement('canvas');
            const tempCtx = tempCanvas.getContext('2d');
            const smallW = Math.max(1, Math.ceil(r.w / pixelSize));
            const smallH = Math.max(1, Math.ceil(r.h / pixelSize));
            tempCanvas.width = smallW;
            tempCanvas.height = smallH;
            tempCtx.drawImage(ctx.canvas, r.x, r.y, r.w, r.h, 0, 0, smallW, smallH);
            ctx.imageSmoothingEnabled = false;
            ctx.drawImage(tempCanvas, 0, 0, smallW, smallH, r.x, r.y, r.w, r.h);
            ctx.imageSmoothingEnabled = true;
        }
    }
}
```

**Security note:** Redaction is rendered into the final canvas pixels. There is no way to recover the original data from the exported image. The original in-memory `Image` element is not included in the download — only the rendered canvas output.

### 5. Text / Titles

Add text overlays onto the image.

**Interaction:**
1. Enter Text mode (toolbar button)
2. Click a position on the preview to place text anchor
3. Type text in an input field
4. Adjust properties via a small control panel:
   - Font size (12–200px, slider + input)
   - Font family: Sans-serif, Serif, Monospace (system fonts only — no external font loading)
   - Colour: picker input (default white, with black outline for readability)
   - Bold / Italic toggles
   - Alignment: Left / Centre / Right
   - Text outline: on/off (black stroke behind text for contrast on any background)
5. Drag to reposition
6. Each text item shown in operations list with preview

**Implementation:**

```javascript
function applyText(ctx, { text, x, y, fontSize, fontFamily, color, align, bold, italic, outline }) {
    const style = `${italic ? 'italic ' : ''}${bold ? 'bold ' : ''}${fontSize}px ${fontFamily}`;
    ctx.font = style;
    ctx.textAlign = align || 'left';
    ctx.textBaseline = 'top';

    if (outline) {
        ctx.strokeStyle = '#000000';
        ctx.lineWidth = Math.max(2, fontSize / 10);
        ctx.lineJoin = 'round';
        ctx.strokeText(text, x, y);
    }

    ctx.fillStyle = color || '#ffffff';
    ctx.fillText(text, x, y);
}
```

**Multi-line:** Split on `\n`. Render each line offset by `fontSize * 1.2` vertically.

**Font families (system fonts only, no CDN):**

| Option | CSS value |
|---|---|
| Sans-serif | `system-ui, -apple-system, sans-serif` |
| Serif | `Georgia, 'Times New Roman', serif` |
| Monospace | `'Courier New', Consolas, monospace` |

## Tool Page: Thin Orchestrator

The `index.html` is ~100 lines of glue code. It does not contain image processing logic. It:

1. Imports and mounts the shared header/footer/dropzone
2. Creates an `<sg-image-editor>` element
3. Wires the dropzone's `file-selected` event to the editor's `loadImage()` method
4. Wires the editor's `sg-image-export` event to trigger a download
5. Adds the privacy message and SG/Send CTA in the footer

```html
<script type="module">
    import '/components/site-header/v1/v1.0/v1.0.1/sg-site-header.js';
    import '/components/site-footer/v1/v1.0/v1.0.0/sg-site-footer.js';
    import '/components/upload-dropzone/v1/v1.0/v1.0.0/sg-upload-dropzone.js';
    import '/components/image-editor/v1/v1.0/v1.0.0/sg-image-editor.js';

    const dropzone = document.querySelector('sg-upload-dropzone');
    const editor   = document.querySelector('sg-image-editor');

    dropzone.addEventListener('file-selected', (e) => {
        editor.loadImage(e.detail.file);
        dropzone.hidden = true;
        editor.hidden = false;
    });

    editor.addEventListener('sg-image-export', (e) => {
        const { blob, filename } = e.detail;
        const a = document.createElement('a');
        a.href = URL.createObjectURL(blob);
        a.download = filename;
        a.click();
        URL.revokeObjectURL(a.href);
    });
</script>
```

All the complexity lives in the components and core module. The tool page is disposable — the components are the value.

## Limits and Error Handling

| Condition | Behaviour |
|---|---|
| Image > 50MB | Warning: "Large images may be slow." Allow anyway. |
| Image > 200MB | Hard block: "Image too large for browser processing." |
| Not an image file | "Unsupported file type. Please select an image (PNG, JPG, WebP, AVIF, GIF)." |
| AVIF not supported | Grey out AVIF option: "Not supported in this browser" |
| Canvas exceeds max dimensions | Browsers limit canvas to ~16384×16384. If image exceeds, auto-scale down with notice. |
| Resize to 0 or negative | Inline validation, disable Apply |
| Crop region < 1×1 px | Ignore the crop attempt |

---

## Memory Management

- Original `Image` element kept in memory for undo/re-render
- Preview canvas re-rendered on each operation change
- Only one image loaded at a time — loading a new image clears previous state
- On download: render final canvas → export to blob → trigger download → revoke blob URL
- No Blob URLs held long-term except for active preview
