## What We're Building

A standalone browser tool at `tools.sgraph.ai/en-gb/video-splitter/` that splits, trims, and extracts audio/video from media files using FFmpeg compiled to WebAssembly. No upload, no server, everything client-side.

**Three core operations:**
1. **Split** — divide a video into multiple clips (fixed-length or custom segments)
2. **Trim** — cut from both ends to keep just the portion you want
3. **Extract streams** — separate audio and video into individual files (e.g. get just the audio from a video)

### New Core Module + Components (the heavy lifting)

The tool page is a thin orchestrator. The actual work lives in reusable modules:

```
core/video/v1/v1.0/v1.0.0/
  sg-video.js              # Pure functions: loadFFmpeg(), splitVideo(), getVideoInfo()
  manifest.json

components/video-splitter/v1/v1.0/v1.0.0/
  sg-video-splitter.js     # Web Component: segment config UI, progress, results list
  sg-video-splitter.html
  sg-video-splitter.css
  manifest.json
```

**`sg-video.js`** — core module (no UI). Manages FFmpeg WASM lifecycle, virtual filesystem, all FFmpeg commands. Exports:
- `loadFFmpeg()` — lazy load FFmpeg WASM from CDN, returns instance
- `splitVideo(ffmpeg, file, segments)` — split a file into segments, yields blobs
- `trimVideo(ffmpeg, file, start, end)` — trim to keep only the specified range
- `extractAudio(ffmpeg, file)` — extract audio stream only (no video)
- `extractVideo(ffmpeg, file)` — extract video stream only (no audio)
- `getVideoInfo(file)` — extract duration/dimensions/hasAudio/hasVideo via native `<video>` element
- `parseTime(input)` — parse `mm:ss`, `hh:mm:ss`, plain seconds
- `formatTime(seconds)` — format seconds back to `mm:ss` or `hh:mm:ss`
- `isWasmSupported()` — check browser WASM support

**`<sg-video-splitter>`** — component (all the UI). Mode selector (split/trim/extract), segment editor, trim handles, progress display, results list with play/download buttons. Imports `sg-video.js` for processing. Emits events: `sg-split-start`, `sg-split-complete`, `sg-split-error`.

This means a future video compressor tool reuses `sg-video.js` with a different component. And send.sgraph.ai can import `sg-video.js` directly if it ever needs to process media before upload.

## User Flow

```
1. Land on page → see dropzone ("Drop a video or audio file")
2. Select/drop file → show: filename, duration, file size, video preview player
3. Choose operation mode:

   [Split] [Trim] [Extract Audio/Video]

   a) Split mode:
      - Fixed length: "Split every [30] seconds" → segments auto-calculated
      - Custom segments: add rows with [start] → [end] time inputs
      → Click [Split] → produces multiple clips

   b) Trim mode:
      - Set start point: [ 0:15 ]  (trim from beginning)
      - Set end point:   [ 2:10 ]  (trim from end)
      - Preview shows the kept region (darkened outside)
      → Click [Trim] → produces one trimmed file

   c) Extract mode:
      - [Extract Audio Only] → produces audio file (MP4/AAC or MP3)
      - [Extract Video Only] → produces silent video file
      → One click, no config needed

4. "Loading FFmpeg..." (first time only, ~30MB, progress bar)
5. Results appear:
   → Clip 1 | 0:15–2:10 | 1:55 | 42 MB | [▶ Play] [↓ Download]
   → (or multiple clips for split mode)
   → [Download All as ZIP]

6. Share via SG/Send:
   → <sg-send-drop> component below results
   → Drop any result file (or click "Share via SG/Send")
   → Encrypt + upload → friendly token + copy + open link
```

## Technical Implementation

### FFmpeg Integration

```javascript
import { FFmpeg } from 'https://unpkg.com/@ffmpeg/ffmpeg@0.12.10/dist/esm/index.js';
import { fetchFile } from 'https://unpkg.com/@ffmpeg/util@0.12.1/dist/esm/index.js';

let ffmpeg = null;

async function loadFFmpeg() {
    ffmpeg = new FFmpeg();
    ffmpeg.on('progress', ({ progress }) => {
        updateProgress(progress);
    });
    await ffmpeg.load();
}
```

### Split Command (per segment)

```
-ss {start} -t {duration} -i input.mp4 -c copy segment_N.mp4
```

`-c copy` = stream copy, no re-encoding. Fast (seconds, not minutes). Splits at nearest keyframe.

### Trim Command

Trim keeps only the portion between start and end, cutting from both ends:

```
-ss {start} -to {end} -i input.mp4 -c copy trimmed.mp4
```

Same `-c copy` — no re-encoding, keyframe-accurate. The preview player should visually indicate the kept region.

### Extract Audio Command

Strip the video stream, keep only audio:

```
-i input.mp4 -vn -c:a copy audio.aac
```

`-vn` = no video. `-c:a copy` = copy audio stream as-is (no re-encoding). Output format depends on the source audio codec (AAC → `.aac` or `.m4a`, MP3 → `.mp3`).

### Extract Video Command

Strip the audio stream, keep only video:

```
-i input.mp4 -an -c:v copy video.mp4
```

`-an` = no audio. `-c:v copy` = copy video stream as-is.

### Virtual Filesystem

```javascript
// Write input to FFmpeg's virtual FS
await ffmpeg.writeFile('input.mp4', await fetchFile(file));

// Run split for each segment
await ffmpeg.exec(['-ss', start, '-t', duration, '-i', 'input.mp4', '-c', 'copy', `segment_${n}.mp4`]);

// Read output
const data = await ffmpeg.readFile(`segment_${n}.mp4`);
const blob = new Blob([data.buffer], { type: 'video/mp4' });
const url = URL.createObjectURL(blob);

// Clean up virtual FS entry after creating blob URL
await ffmpeg.deleteFile(`segment_${n}.mp4`);
```

### Video Metadata Extraction

Before splitting, extract duration and display info using the native `<video>` element:

```javascript
function getVideoInfo(file) {
    return new Promise((resolve) => {
        const video = document.createElement('video');
        video.preload = 'metadata';
        video.onloadedmetadata = () => {
            resolve({
                duration: video.duration,
                width:    video.videoWidth,
                height:   video.videoHeight,
            });
            URL.revokeObjectURL(video.src);
        };
        video.src = URL.createObjectURL(file);
    });
}
```

### Time Input Parsing

Accept multiple formats, convert to seconds:

| Input | Parsed |
|---|---|
| `30` | 30s |
| `1:30` | 90s |
| `01:30` | 90s |
| `1:02:30` | 3750s |

```javascript
function parseTime(input) {
    const parts = input.trim().split(':').map(Number);
    if (parts.some(isNaN)) return null;
    if (parts.length === 1) return parts[0];
    if (parts.length === 2) return parts[0] * 60 + parts[1];
    if (parts.length === 3) return parts[0] * 3600 + parts[1] * 60 + parts[2];
    return null;
}
```

### Download All as ZIP

Use JSZip (same library used by SG/Send) to package all clips:

```javascript
import JSZip from 'https://cdn.jsdelivr.net/npm/jszip@3.10.1/dist/jszip.min.js';

async function downloadAllAsZip(clips) {
    const zip = new JSZip();
    for (const clip of clips) {
        const response = await fetch(clip.blobUrl);
        zip.file(clip.filename, await response.blob());
    }
    const blob = await zip.generateAsync({ type: 'blob' });
    downloadBlob(blob, 'clips.zip');
}
```

## Limits and Error Handling

| Condition | Behaviour |
|---|---|
| File > 200MB | Warning: "Large files may be slow. Consider FFmpeg on your computer for files over 500MB." |
| File > 500MB | Hard block: "File too large for browser processing." |
| Not MP4 | Warning + attempt anyway (FFmpeg handles many formats). Show "Best results with MP4." |
| FFmpeg load fails | "Could not load FFmpeg. Check your connection and try again." + retry button |
| Segment with start ≥ end | Inline validation error, disable Split button |
| Segment extends beyond video duration | Clamp to video duration, show notice |
| Browser doesn't support WASM | "Your browser doesn't support WebAssembly. Try Chrome, Firefox, or Edge." |

---

## Memory Management

- Write input file to virtual FS once
- After each segment: read output → create Blob URL → delete virtual FS entry
- After all segments: delete input from virtual FS
- On "Start Over" / new file: revoke all Blob URLs via `URL.revokeObjectURL()`
