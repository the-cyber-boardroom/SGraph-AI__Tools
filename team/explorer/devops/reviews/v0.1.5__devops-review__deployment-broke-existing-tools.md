# DevOps Review: v0.1.5 Deployment Broke Existing Tools (404s)

**Version:** v0.1.5
**Date:** 28 March 2026
**Role:** DevOps (Explorer team)
**Session:** `claude/start-tools-explorer-session-WariD`
**Severity:** P0 — all existing tools returned 404 on dev.tools.sgraph.ai

---

## What Happened

When v0.1.5 was deployed to dev, all existing tools (vault-browser, file-encryptor, ssh-keygen, etc.) started returning 404. Only the 2 new tools (image-tools, video-tools) worked.

## Root Cause

The v0.1.5 `en-gb/` directory was created with only the 2 new tools. The deploy script's `--clean-urls-source-version tools/v0/v0.1/v0.1.5` extracts locale content from that folder and syncs it to the S3 clean URL root, **replacing** everything. Since v0.1.5 only had 2 tools, the other 8 were deleted from the clean URL root.

```
v0.1.4/en-gb/  (9 tools)    →  v0.1.5/en-gb/  (2 tools)  =  7 tools lost
```

## The IFD Rule (Violated)

From the SG/Send debrief (section 9):

> "Surgical minor versions = full previous version + deltas"

A minor version bump (v0.1.4 → v0.1.5) must be **additive**. The new version should contain everything from the previous version plus the new additions. It should never be a subset.

## Fix Applied

Copied all 8 missing tool directories from v0.1.4 into v0.1.5:

```
file-encryptor, file-hasher, key-generator, pyodide-repl,
sg-send-cli, ssh-keygen, vault-browser, vault-pyodide
```

v0.1.5 now contains all 10 tools (8 carried forward + 2 new).

## Prevention: Checklist for Future IFD Versions

When creating v0.1.{N+1}:

1. **Start from v0.1.{N}** — copy the entire `en-gb/` directory first
2. **Add new tools** — create new tool directories
3. **Update changed tools** — overwrite only the modified files
4. **Verify count** — `ls en-gb/ | wc -l` must be >= previous version
5. **Copy root files** — i18n/, 404.html, manifest.json, robots.txt, sitemap.xml, index.html
6. **Copy _common/** — or regenerate if tools.css/sg-nav.js changed
7. **Update landing page** — add new tool cards, keep existing ones

## Files That Must Exist in Every IFD Version

```
tools/v0/v0.1/v0.1.{N}/
  _common/css/tools.css
  _common/favicon.svg
  _common/js/sg-nav.js
  en-gb/index.html              ← landing page with ALL tool cards
  en-gb/{every-tool}/index.html ← ALL tools, not just new ones
  i18n/*.json                   ← all locale translation files
  404.html
  index.html                    ← locale redirect
  manifest.json
  robots.txt
  sitemap.xml
```
