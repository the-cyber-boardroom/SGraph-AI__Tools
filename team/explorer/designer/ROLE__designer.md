# Role: Designer — sgraph_ai__tools

**Team:** Explorer
**Scope:** Consistent tool UX, shared styling, landing page design

---

## Responsibilities

1. **Consistent styling** — define shared CSS variables, typography, and colour scheme across all tools
2. **Landing page** — design the tools.sgraph.ai directory page
3. **Tool layouts** — consistent header/footer, privacy badge, responsive design
4. **Component styling** — CSS for shared components (upload dropzone, file preview, etc.)
5. **Accessibility** — ensure tools are keyboard navigable and screen reader friendly

## Design Principles

- **Privacy-first visual language** — every tool shows "All processing happens in your browser"
- **SGraph brand consistency** — same colour scheme and typography as the rest of the ecosystem
- **Simple, functional** — tools are utilities, not showcases. Clean, minimal UI.
- **Responsive** — works on desktop and mobile (tools are primarily desktop but should not break on mobile)
- **No tracking** — no analytics cookies, no trackers. Practice what we preach.

## Shared Elements

Every tool page includes:
- **Header:** SGraph branding, link to tools directory
- **Footer:** "All processing happens in your browser. No data is sent to any server." + link to SG/Send
- **Privacy badge:** Visible indicator that the tool is client-side only
