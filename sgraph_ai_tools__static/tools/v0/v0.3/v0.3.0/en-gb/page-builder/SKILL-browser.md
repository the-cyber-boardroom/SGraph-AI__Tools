# SG/Send Theme Explorer — Browser / Automation Guide

**Tool:** SG/Send Theme Explorer v0.1.42
**URL:** `/en-gb/page-builder/`

## Overview

The tool exposes a `window.__tool` API object after load. Use it from the browser console,
Playwright, Puppeteer, or any other browser-automation context to drive the editor
programmatically.

---

## Detecting Tool Ready

The API is available once the module finishes loading. Check for `window.__tool`:

```javascript
// Browser console — poll until ready
const tool = await new Promise(resolve => {
    const t = setInterval(() => {
        if (window.__tool) { clearInterval(t); resolve(window.__tool); }
    }, 100);
});
```

In Playwright:

```javascript
await page.waitForFunction(() => !!window.__tool);
const tool = await page.evaluateHandle(() => window.__tool);
```

---

## API Actions

All actions are available via `window.__tool.call(action, ...args)`:

| Action | Async | Description |
|---|---|---|
| `setJson` | no | Load a `_page.json` object or JSON string into the editor |
| `getJson` | no | Return the current parsed JSON, or `null` if invalid |
| `setTheme` | no | Switch to a named theme scheme |
| `getTheme` | no | Return the current theme name |
| `render` | yes | Force an immediate re-render |
| `getState` | no | Return `{ theme, viewport, valid }` |

## Common Recipes

### Load a _page.json and render it

```javascript
window.__tool.call('setJson', {
    title: 'My Report',
    theme: { mode: 'light', accent: '#1a8fe0', font: 'sans', background: '#f7f9fc' },
    components: [
        { type: 'hero', title: 'My Report', subtitle: 'Generated by the pipeline' },
        {
            type: 'section',
            title: 'Summary',
            children: [
                { type: 'text', content: 'Key findings go here.' }
            ]
        }
    ]
});
```

### Switch theme

```javascript
window.__tool.call('setTheme', 'dark-deck');
// Available: default | navy | slate | minimal | brand | dark-deck
```

### Read back the current JSON

```javascript
const json = window.__tool.call('getJson');
console.log(JSON.stringify(json, null, 2));
```

### Force re-render after manual textarea edit

```javascript
await window.__tool.call('render');
```

### Check tool state

```javascript
const { theme, viewport, valid } = window.__tool.call('getState');
console.log(`theme=${theme}, viewport=${viewport}, valid=${valid}`);
```

## Playwright End-to-End Example

```javascript
import { test, expect } from '@playwright/test';

test('page-builder renders hero block', async ({ page }) => {
    await page.goto('https://tools.sgraph.ai/en-gb/page-builder/');
    await page.waitForFunction(() => !!window.__tool);

    await page.evaluate(() => {
        window.__tool.call('setJson', {
            title: 'Test Page',
            theme: { mode: 'light', accent: '#4ecdc4', font: 'sans', background: '#ffffff' },
            components: [
                { type: 'hero', title: 'Hello World', subtitle: 'Playwright test' }
            ]
        });
    });

    // Wait for the debounced render (200 ms) to complete
    await page.waitForTimeout(400);

    // Verify the hero rendered
    const hero = page.locator('.plr-hero');
    await expect(hero).toBeVisible();
    await expect(hero).toContainText('Hello World');
});
```

## Notes

- `render` is the only async action — it resolves after `PageLayoutRenderer.render()` completes
- `setJson` triggers an automatic re-render; no need to call `render` after it
- `setTheme` also triggers a re-render
- The tool is stateless — refreshing the page resets to the demo JSON
