How to Update Demo Content

Run these sgit commands to update a vault object and the manifest: 


# Set up
export DEMO_VAULT_KEY="your-passphrase:your-vault-id"
sgit clone --sparse "$DEMO_VAULT_KEY" ./demo-vault

# Write new content
NEW_ID=$(echo "# Updated hero copy" | \
  sgit write content/intro.md ./demo-vault)

# Update manifest
sgit read manifests/home.json ./demo-vault | \
  jq ".slots.hero.object_id = \"$NEW_ID\"" | \
  sgit write manifests/home.json ./demo-vault
sgit push ./demo-vault

# → Browser fetches new blob, decrypts, renders
