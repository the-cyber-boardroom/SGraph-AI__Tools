Vault Browser

Open and browse SG/Send vaults entirely in your browser. Keys are derived locally using PBKDF2. Files are fetched and decrypted client-side. Nothing leaves your device.

How It Works

Your vault key is split into a passphrase and vault ID. PBKDF2-SHA256 (600,000 iterations) derives read and write keys locally. File IDs are computed via HMAC-SHA256. Encrypted files are fetched from the API and decrypted in your browser using AES-256-GCM. Same crypto as sg-send-cli.
