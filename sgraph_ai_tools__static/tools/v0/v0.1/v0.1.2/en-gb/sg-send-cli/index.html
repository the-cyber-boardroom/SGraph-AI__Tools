About sg-send-cli

sgraph-ai-app-send is the Python CLI for SG/Send encrypted vaults. It provides git-like operations (init, commit, push, pull, clone) with client-side encryption.

  • All encryption uses PBKDF2-SHA256 (600K iterations) + AES-256-GCM
  • Vault keys derive deterministic read/write keys and file IDs
  • In-memory API mode — no external server needed for testing
  • Same code that runs on your machine, now running in WebAssembly
