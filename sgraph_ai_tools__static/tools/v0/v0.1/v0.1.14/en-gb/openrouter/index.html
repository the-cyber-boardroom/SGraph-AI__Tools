User Vault
Your OpenRouter API key is encrypted with AES-256-GCM and stored locally. Enter a token (passphrase) to lock/unlock the vault. The key never leaves your device.
OpenRouter Admin ⬤ disconnected
Admin Vault
Your OpenRouter management key is stored separately from your user key. Management keys can create, modify and revoke provisioned sub-keys but cannot make completion API calls. Obtain one at openrouter.ai/settings/management-keys.
