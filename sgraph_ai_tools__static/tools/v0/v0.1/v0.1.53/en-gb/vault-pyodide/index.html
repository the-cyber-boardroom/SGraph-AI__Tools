Vault (Pyodide) Experimental

Run Python vault operations entirely in the browser via Pyodide (CPython compiled to WebAssembly). This tool tests whether sg-send-cli's vault crypto can work without any Python installation.

Step 1 — Load Python Runtime

Downloads Pyodide (~20 MB) from CDN. First load may take 10-30 seconds depending on connection. Subsequent visits use browser cache.

Step 2 — Dependency Compatibility Check

Tests whether sg-send-cli's key dependencies are available in the Pyodide WASM environment.

Step 3 — Vault Key Derivation: Python vs JavaScript

Derives vault keys using both Python (via Pyodide) and JavaScript (via Web Crypto API), then compares the results. Both should produce identical output — proving wire compatibility.

Use a known test vector or enter any key in passphrase:vault_id format

What This Proves

If Python and JavaScript produce identical vault keys, it confirms:

  • Pyodide can run vault crypto in the browser (no Python install needed)
  • PBKDF2-SHA256 with 600K iterations works in WASM
  • HMAC-SHA256 file ID derivation is cross-language compatible
  • sg-send-cli could eventually run entirely client-side

The pure JS Vault Browser uses only Web Crypto and is faster (no WASM download). This tool validates that Pyodide is a viable path for more complex Python vault operations (branching, merging) that don't have JS equivalents yet.
