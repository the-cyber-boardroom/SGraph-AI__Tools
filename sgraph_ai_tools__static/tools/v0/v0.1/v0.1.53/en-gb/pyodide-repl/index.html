Python REPL Pyodide

Interactive Python console running entirely in your browser. CPython compiled to WebAssembly via Pyodide — no installation, no server, no data leaves your machine.

Console

Click Start Python to download the Pyodide runtime (~20 MB, cached after first load).

Shift+Enter to run  |  Enter for newline  |  Up/Down arrows to recall history

Install Packages

Click a package to install it via micropip. Most pure-Python PyPI packages work.

What Can You Do?

This is a full CPython interpreter running in WebAssembly. You can:

  • Explore the Python standard library (json, hashlib, hmac, os, sys, ...)
  • Install and test PyPI packages (pydantic, cryptography, httpx, ...)
  • Run data validation experiments with Pydantic models
  • Test crypto operations (PBKDF2, AES, HMAC, hashing)
  • Prototype code without installing anything on your machine

For vault-specific operations, see the SG/Send CLI tool or the Vault (Pyodide) comparison tool.
