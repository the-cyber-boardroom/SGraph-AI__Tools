How it works

This tool uses the Web Crypto API to generate Ed25519 SSH key pairs directly in your browser:

  • Keys are generated using crypto.subtle.generateKey()
  • The private key is formatted in OpenSSH PEM format
  • The public key is formatted in OpenSSH authorized_keys format
  • No data leaves your browser at any point
  • Requires a secure context (HTTPS or localhost)
