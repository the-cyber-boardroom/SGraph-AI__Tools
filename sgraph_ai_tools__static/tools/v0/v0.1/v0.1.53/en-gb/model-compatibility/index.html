Test Criteria
🔧
Simple tool call
Model calls a single tool with correct JSON args on first attempt.
🔗
Chained tool calls
Model uses results from one tool to inform the next call (multi-step).
📋
JSON schema adherence
Model respects response_format: json_schema, producing valid output.
🛑
Stop condition
Model correctly returns finish_reason:'stop' when done (not looping).
⚡
Streaming
Streams tool_calls deltas correctly (index-based accumulation works).
🔄
Error recovery
Model gracefully handles tool errors returned in tool result messages.
How to read this table: Tests are run against the sg-tool-runner + sg-agentic-loop pipeline. "Partial" means the feature works but has known caveats (see Notes column). All OpenRouter models are tested via the OpenAI-compat endpoint. Ollama models are tested via the local Ollama server (http://localhost:11434). Anthropic and OpenAI are tested via their native APIs.
