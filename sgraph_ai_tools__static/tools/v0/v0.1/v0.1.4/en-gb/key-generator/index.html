Key Generator

Instead of random strings like "Xk9mP2vR7w", create encryption keys you can actually remember and share over the phone.

How It Works

  1. Pick two words (or let us choose randomly)
  2. A short numeric suffix is added for extra security
  3. Your words are turned into a 256-bit encryption key using PBKDF2 (600,000 iterations)
  4. The resulting key is identical in strength to a random AES-256 key

Use with SG/Send

Send encrypted files with a key your recipient can type from memory:

"The key is apple mango 56"

All processing happens in your browser. No keys are sent to any server.
