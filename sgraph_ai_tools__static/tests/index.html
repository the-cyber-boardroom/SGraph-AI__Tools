tests.sgraph.ai

Browser-based test suite for tools.sgraph.ai core modules

  • sg-vault-client.js ~3s (PBKDF2)
  • sg-pyodide.js ~30s (downloads Pyodide)

How to run: Click a test to open it. Each page runs automatically and shows PASS/FAIL results. Tests use the Web Crypto API and require a secure context (HTTPS or localhost).

Pyodide test downloads ~20 MB of WASM on first run. Subsequent runs use browser cache. The test validates that Python and JavaScript produce identical vault keys — proving sg-send-cli compatibility.
