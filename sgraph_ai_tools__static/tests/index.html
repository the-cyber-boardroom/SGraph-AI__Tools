How to run: Click any test to open it. Pages run automatically and show PASS/FAIL results. Requires a secure context (HTTPS or localhost).

Unit — isolated component tests, fast (<1s). Smoke — integration tests verifying tool pages mount correctly. Demo — interactive pages, not automated. Slow — downloads WASM (~20 MB), use browser cache on repeat runs.
